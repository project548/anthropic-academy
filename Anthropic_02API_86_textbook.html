Agents and tools— Agent のコア構造 — LLM がループでtool を呼び続ける

Anthropic Academy / コース02 Claude with the Anthropic API

① Agent の本質

Agent = LLM が tool を持って、ループで自律的に行動を選ぶ 仕組み。Workflow と違い、フローが事前に決まっておらず、LLM が状況を見て次の手を決める。

核心構造: 
while not 完了:
    next_action = LLM(現在の状況, available_tools)
    if next_action.is_final:
        return next_action.text
    result = execute_tool(next_action.tool, next_action.input)
    現在の状況.append(result)

② Agent に必要な要素

  1. LLM: 判断する頭脳 (Claude)
  2. Tools: 行動する手足 (file read / API call / DB query 等)
  3. Loop: 何度も繰り返す制御構造
  4. Termination: いつ終わるかの判定 (Claude が end_turn 出すまで)
  5. Memory: 過去の行動・結果を覚える (messages 履歴)

③ ミニ Agent 実装

tools = [get_weather_schema, send_email_schema, search_db_schema]

def run_agent(user_request: str):
    messages = [{"role": "user", "content": user_request}]

    while True:
        response = client.messages.create(
            model="claude-opus-4-7",
            max_tokens=4096,
            tools=tools,
            messages=messages
        )
        messages.append({"role": "assistant", "content": response.content})

        # 終了判定
        if response.stop_reason != "tool_use":
            return response.content[0].text  # 最終応答

        # tool 実行
        tool_results = []
        for block in response.content:
            if block.type == "tool_use":
                result = run_tool(block.name, block.input)
                tool_results.append({
                    "type": "tool_result",
                    "tool_use_id": block.id,
                    "content": result
                })
        messages.append({"role": "user", "content": tool_results})

④ Workflow との関係

Workflow は 事前にフローを決める。Agent は その場で Claude が決める。実装上の違い:

  • Workflow: コード側で if/else / chain / parallel を組む
  • Agent: LLM 自身に tool を渡して「自由に使え」と委ねる
選択基準: 「フローが予測可能」=workflow / 「未知タスクへの柔軟対応」=agent。Anthropic 推奨は まず workflow、限定部分のみ agent化。

⑤ 中学生向けに例えると

Workflow = レシピ通り。Agent = 「冷蔵庫見て自由に料理して」と頼む。Agent の方が柔軟だが、予測不能で失敗もする。
