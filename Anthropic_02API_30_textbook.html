Prompt engineering— プロンプト工学の全体像 (このモジュールの導入)

Anthropic Academy / コース02 Claude with the Anthropic API

① Prompt engineering って何?

LLM に 「期待した結果を出させる」プロンプトを設計する技術。同じClaudeでも、プロンプトの書き方で精度が10倍変わる。

Fine-tuning との違い: fine-tuning はモデル自体を訓練 (高コスト)。prompt engineering はテキストの書き方だけで挙動を変える (低コスト・即時効果)。

② Anthropic 公式7原則

原則意味本コース該当章
1. Clear & direct明確かつ直接的に指示#31
2. Specific具体的に#32
3. XML tags構造化に XMLタグ使用#33
4. Examples例を示す (few-shot)#34
5. Chain of Thought段階思考を誘導—
6. Role prompting役割を与える#14 system
7. Prefill response応答の出だしを与える—

③ 改善サイクル

  1. 初期プロンプトを書く
  2. eval (#22-#28) で客観スコア測定
  3. 7原則を1つずつ適用して改善
  4. 再evalで効果確認
  5. 改善があれば採用、なければ元に戻す
「直感で改善」ではなく「eval スコアで改善」する習慣をつける。

④ 中学生向けに例えると

家庭教師に質問するときの「聞き方」を工夫する技術。「教えて」より「○ページの問題を中学生にわかるように2文で説明して」のほうが良い答えが返ってくる。それがprompt engineering。

⑤ 理解度チェック

Q1. Prompt engineering と Fine-tuning の違いは?

fine-tuning = モデル自体を再訓練 (高コスト)。prompt engineering = テキスト書き方だけで挙動制御 (低コスト・即時)。

Q2. 7原則は?

Clear & direct / Specific / XML tags / Examples / Chain of Thought / Role / Prefill response
