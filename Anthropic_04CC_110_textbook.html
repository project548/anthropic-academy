Claude Code setup— Claude Code のインストール・初期認証

Anthropic Academy / コース04 Claude Code

① 前提環境

  • Node.js 18+ (公式推奨は 20+)
  • macOS / Linux / Windows (Windows は WSL 推奨だが native 対応もあり)
  • git (プロジェクトで使う場合)
  • Anthropic アカウント (Pro/Max サブスク or API key)
必須: ターミナルアプリ (Terminal.app / iTerm2 / Windows Terminal / WSL bash 等)。Cursor / VS Code の統合ターミナルでも動く。

② インストール

# npm でグローバルインストール
npm install -g @anthropic-ai/claude-code

# 確認
claude --version
# → 例: 1.x.x

# 起動
claude

初回起動時に対話的に設定が始まる。OS の認証 GUI が開くケースもある。

③ 認証方法 (2択)

  • A. Claude Pro/Max サブスクリプション: ブラウザで claude.ai ログイン → ターミナルが自動で認証連動 (推奨・コスト固定)
  • B. API key: ANTHROPIC_API_KEY 環境変数で設定 (従量課金・大規模利用向け)
# A 方式は初回起動時にブラウザが開いて完了

# B 方式
export ANTHROPIC_API_KEY="sk-ant-xxxxx"
claude

④ 基本コマンド

# プロジェクトディレクトリで起動
cd ~/my-project
claude

# プロンプト1個だけ実行 (非対話モード)
claude "package.json の依存を要約して"

# 標準入力からパイプ
git log --oneline -20 | claude "最近の変更を3行でまとめて"

# モデル指定
claude --model claude-opus-4-7

# 終了
> /exit  または Ctrl+D

⑤ 主要設定ファイル

  • ~/.claude/CLAUDE.md: 全プロジェクト共通の自分用ルール
  • ~/.claude/settings.json: 全体設定 (theme / hooks / permissions)
  • ~/.claude/commands/*.md: 自分用 slash commands
  • {project}/CLAUDE.md: プロジェクト固有ルール
  • {project}/.claude/settings.json: プロジェクト固有設定

⑥ トラブルシューティング

  • command not found: claude → npm の global bin が PATH に入っているか確認
  • 認証ループする → ~/.claude/auth.json 削除 → 再ログイン
  • 遅い → ネットワーク確認 / --model claude-haiku-4-5 で軽量モデルに
  • 権限エラー → ~/.claude/settings.json の permissions セクション確認

⑦ 中学生向けに例えると

新しいアプリをスマホに入れる作業。① ストアからダウンロード (npm install) → ② アカウントでログイン (Pro/API key) → ③ 最初の画面で簡単な設定 (CLAUDE.md)。これだけで使い始められる。
