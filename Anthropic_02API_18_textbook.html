Response streaming — ストリーミング・答えを少しずつ受け取るしくみ

Anthropic Academy / コース02 Claude with the Anthropic API

① ストリーミングってなに？

AIに質問すると、答えが画面に出るまで 10〜30秒 待たされることがあります。その間、ぐるぐる回るマークだけ見せられて、ユーザーは「動いてるのかな？」と不安になります。

そこで使うのが ストリーミング（streaming） という技術。AIが答えを作りながら、できた部分から少しずつ送って画面に出す方法です。

図① 普通の応答（左：待ちでイライラ）とストリーミング（右：すぐ読み始める）

② どんなしくみ？

  1. サーバーが「ストリーミング有効」でAIにメッセージを送る
  2. AIはまず「受け取りました」だけ返事する（本文はまだない）
  3. そのあと、テキストのかけら（チャンク）を連続して送ってくる
  4. サーバーは受け取り次第クライアントに転送、画面に語句が積み上がる
大事なポイント: これらは すべて1回のリクエスト の中で起きること。何度もAPIを呼んでいるわけではない。

③ ストリームのイベント6種

ストリーミングを有効にすると、AIから次の6種類のイベントが流れてきます。

英語名意味
MessageStart新しいメッセージの送出が始まる
ContentBlockStartテキスト・ツール使用などの新ブロック開始
ContentBlockDelta★本命★ 実際のテキストの断片が入っている
ContentBlockStop現在のコンテンツブロック完了
MessageDelta現在のメッセージの状態更新
MessageStopメッセージ送出完了
覚え方: 画面に表示したい文字は ContentBlockDelta の中にある。これだけ拾えば十分なケースが多い。

図② イベントの流れ（★本命= ContentBlockDelta）

④ コードで書いてみよう

パターン1: 基本のストリーミング

stream=True を加えると、戻り値が「イベントの繰り返し」になります。

stream = client.messages.create(
    model=model,
    max_tokens=1000,
    messages=messages,
    stream=True
)
for event in stream:
    print(event)

パターン2: テキストだけ取り出す（簡略版）

「ノイズは要らない、テキストだけほしい」ときは messages.stream() の text_stream を使います。

with client.messages.stream(
    model=model,
    max_tokens=1000,
    messages=messages
) as stream:
    for text in stream.text_stream:
        print(text, end="")

パターン3: 最終メッセージも一緒に取る

ユーザー画面には少しずつ表示、最後に 完全な1メッセージ も欲しい場合（DB保存など）。

with client.messages.stream(
    model=model,
    max_tokens=1000,
    messages=messages
) as stream:
    for text in stream.text_stream:
        # ここで各チャンクをクライアントに転送
        pass

    final_message = stream.get_final_message()

get_final_message() がストリーム終了後にすべての断片を組み立て直した 完成版メッセージ を返します。

⑤ 食卓の例えで覚える

食卓の例えストリーミング
料理を全部作り終えてから一皿で出す普通の応答（待ち時間が長い）
できた料理から1品ずつ運ぶストリーミング
運ばれてくる料理ひとつひとつContentBlockDelta
「いただきます」「ごちそうさま」の合図MessageStart / MessageStop
食後に1枚のメニュー表をもらうget_final_message()

⑦ 理解度チェック

Q1. ストリーミングを使うと、ユーザーは何が嬉しい？

10〜30秒待たされず、文字が少しずつ出始めるので「動いている」と分かる。読み始めも早く、体験が軽くなる。

Q2. 6種類のイベントのうち、画面に文字を出すために一番大事なのは？

ContentBlockDelta。実際のテキストの断片がここに入っている。

Q3. ストリーミングしつつ、最後に完全なメッセージをDBに保存したい。どう書く？

messages.stream() でループしてから、stream.get_final_message() を呼ぶ。両方が1回のリクエスト内で取れる。
