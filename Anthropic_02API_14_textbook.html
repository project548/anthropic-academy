System prompts— Claude の役割と振る舞いを定義する

Anthropic Academy / コース02 Claude with the Anthropic API

① System prompt とは?

Claude に 「あなたは○○の専門家」「△△のように振る舞え」 と指示する特別なパラメータ。messages とは別の system= フィールドで渡す。会話の最上位指示。

user message と違い、会話全体に影響する。Claude のキャラクター・口調・専門領域・出力フォーマット等を制御。

② コード例

response = client.messages.create(
    model="claude-sonnet-4-6",
    max_tokens=1024,
    system="あなたは関西弁で答える歴史学者です。"
           "明治時代以降の出来事には詳しく、それ以前は控えめに答えてください。",
    messages=[{"role": "user", "content": "坂本龍馬について教えて"}]
)
# → "ええ質問やなあ。坂本龍馬は江戸末期の人物やけど、わいの専門は明治以降やから..."

③ 効果的な system prompt のコツ

  1. 役割を明示: 「あなたは○○です」
  2. 口調・トーン指定: 「丁寧に」「フランクに」「専門用語を避けて」
  3. 出力フォーマット: 「JSONで返す」「箇条書きで」「200字以内」
  4. 制約・禁止事項: 「医療アドバイスは禁止」「個人情報を出さない」
  5. 例示: 望ましい応答の例を含める (few-shot)

④ 中学生向けに例えると

劇のシナリオに 「あなたは医者役」「あなたは探偵役」 と書いてあるようなもの。Claude はその役を演じきって、ユーザーとの対話 (messages) を進める。

⑤ 理解度チェック

Q1. system と user の違いは?

system = 会話全体のキャラ・指示 (一度だけ設定)。user = 毎ターンの質問。

Q2. system prompt が長くなりがち

長くなるなら #60 prompt caching で90%コスト圧縮。固定指示はキャッシュ対象に最適。
