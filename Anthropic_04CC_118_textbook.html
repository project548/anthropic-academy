Github integration— Claude Code と GitHub の連携

Anthropic Academy / コース04 Claude Code

① 何ができる?

Claude Code は GitHub と深く連携する。2つの主要経路がある:

  • gh CLI 経由: ターミナルから gh pr create 等を Claude が実行
  • MCP GitHub server 経由: API 直接呼び出し (Issue / PR / Code 検索)
核心: 「自然言語で GitHub 操作」が可能になる。「open な PR 一覧」「このバグを Issue 化」「コミット要約を PR description に」など。

② gh CLI 経由 (前提: gh インストール済)

# Claude Code 内で
> Issue を作って: タイトルは "○○", body は△△

# Claude が実行
gh issue create --title "○○" --body "△△"
# → 承認確認 → 実行

③ MCP GitHub server 経由 (推奨)

# セットアップ
claude mcp add github \
  --command "npx" \
  --args "-y @modelcontextprotocol/server-github" \
  --env "GITHUB_PERSONAL_ACCESS_TOKEN=ghp_xxx"

# 使い方 (自然言語)
> リポジトリ myorg/myproject の最新10 Issue を一覧で
> PR #42 のレビューコメントを全部取得して
> "auth" を含むファイルをリポジトリ全体で検索

④ よくある GitHub 連携ワークフロー

  1. Issue 起票: バグ発見 → Claude に概要伝える → Issue 自動生成
  2. PR 作成: 変更 → コミット → PR description を Claude に書かせる
  3. レビュー対応: PR コメント取得 → 該当行を修正 → 再 push
  4. Code 検索: 「○○の使用箇所を全リポジトリで探す」
  5. changelog 生成: マージ済 PR から自動でリリースノート

⑤ 認証・トークン管理

  • Personal Access Token: classic or fine-grained / 必要な scope だけ付与
  • 環境変数で管理: GITHUB_PERSONAL_ACCESS_TOKEN
  • gh CLI: gh auth login 経由で OAuth (推奨)
  • Organization 用: SSO 認可も必要
  • 絶対やらない: トークンをコードにハードコード / commit に含める

⑥ セキュリティ注意点

  • 本番ブランチへの push は 明示承認 推奨
  • force push / branch 削除は禁止設定推奨
  • Issue / PR 本文に内部情報を漏らさないようプロンプト工夫
  • GitHub Actions のトークンを Claude 経由で触らない

⑦ 中学生向けに例えると

「リモコンでテレビとレコーダーを操作」する感じ。Claude Code がリモコン、GitHub がレコーダー。「これ録画して」「これ再生して」と自然な指示で操作できる。ただし「全部消して」は承認必要。
