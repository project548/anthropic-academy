② 振り返りキー概念

Prompt evaluation とは?

Claude のプロンプトを 客観スコアで採点 する手法。「なんとなく良くなった気」から脱却し、データドリブンに改善する。

Model based grading vs Code based grading?

Model based = LLM-as-Judge で別Claudeに採点させる (主観タスク向け)。Code based = 正規表現・キーワード一致等のコード自動採点 (客観タスク向け)。

Test dataset の役割は?

「期待される入出力」のペアを多数用意。プロンプト変更時の回帰テストとして使う。

典型的なeval workflow は?

① Test dataset 生成 → ② 各サンプルにプロンプト適用 → ③ 出力を grading → ④ 平均スコア集計 → ⑤ プロンプト改善 → ②に戻る
