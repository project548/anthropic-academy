Claude Code in action— 実タスクで Claude Code を動かしてみる

Anthropic Academy / コース02 Claude with the Anthropic API

① 何を体感する?

Claude Code が 自然言語の指示 から、ファイル操作・コード生成・テスト実行・git操作まで自律的にこなす様子を実際に動かして確認する。

② シナリオ1: バグ修正

あなた: "src/utils.py の divide 関数で 0除算チェックが抜けている。
        修正してテストも追加して"

Claude Code が自動で:
1. Read("src/utils.py")  # ファイル読込
2. 該当関数を特定
3. Edit("src/utils.py", old_str=..., new_str=...)  # 修正
4. Write("tests/test_utils.py", content=...)  # テスト追加
5. Bash("pytest tests/test_utils.py")  # 実行
6. 結果報告
人間がやる手順を 1回の指示 で完結。途中で確認質問してくれることもあるので安心。

③ シナリオ2: 新機能実装

あなた: "/health エンドポイントを追加して、DB接続とRedis接続を
        確認するヘルスチェックを返すように"

Claude Code が:
1. 既存ルーティング構造を把握 (Glob + Read)
2. /health ハンドラを実装 (Write)
3. DB/Redis接続チェック関数を作成
4. テスト追加
5. 動作確認のためサーバー起動 (Bash)
6. curl で叩いて応答確認

④ シナリオ3: コードレビュー

あなた: "最近の git 変更をセキュリティ観点でレビューして"

Claude Code が:
1. git diff HEAD~5 で直近変更取得
2. SQL injection / XSS / 認証バイパス 等をチェック
3. CRITICAL/HIGH/MEDIUM でラベル付け
4. 修正案を提示

⑤ Claude Code の働き方の特徴

  • 計画 → 実行 → 検証 の3段階を自動でやる
  • 重要操作 (rm / git push 等) は事前確認を取る
  • 失敗したら自分でリトライ or 別アプローチを試す
  • 長時間のタスクでも途中で迷ったら質問してくる

⑥ 中学生向けに例えると

料理を「カレー作って」と頼んだら、材料調達 (Read) → 切る (Edit) → 煮込む (Bash) → 味見 (Test) → 盛り付け まで全部やってくれる助手。途中で「辛さどれくらいにする?」と聞いてくれる。
