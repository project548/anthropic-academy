② 問題セット

Q1. Workflow と Agent の最大の違いは?

A. 制御フローの決まり方。Workflow = 事前に人間が固定 / Agent = LLM が動的に判断。

Q2. Anthropic 推奨の実装順序は?

A. まず Workflow で実装 → 動的判断が必要な部分だけ Agent 化。最初から全部 Agent は過剰設計。

Q3. Parallelization workflow の2サブパターンは?

A. Sectioning (1タスクを並列分割) / Voting (同じタスクを複数回 → 多数決で品質UP)。

Q4. Chaining workflow の本質は?

A. 複数 LLM 呼び出しを 順次接続して、前のステップの出力を次のステップの入力にする。各ステップは小さく確実 → 全体で複雑タスク達成。

Q5. Routing workflow の用途は?

A. 入力を 分類して専用フローへ振り分け。例: カスタマーサポートで refund / technical / billing に振り分け、各専用処理を呼ぶ。

Q6. Orchestrator-workers workflow とは?

A. マスター LLM が 子タスクに動的分割して、各 worker (LLM or tool) に並列実行させて結果統合。

Q7. Evaluator-optimizer workflow とは?

A. 生成 → 評価 → 改善 の ループ。Generator が出力 → Evaluator が採点・FB → Generator が修正 → 合格まで反復。

Q8. Agent ループの終了判定は?

A. response.stop_reason !== "tool_use" (= "end_turn" 等)。それまで tool 実行と再呼び出しをループ。

Q9. Agent に必要な5要素は?

A. ① LLM (頭脳) ② Tools (手足) ③ Loop (制御構造) ④ Termination (終了判定) ⑤ Memory (履歴)。

Q10. Environment inspection の役割は?

A. Agent が 「今どこにいるか・何が使えるか・どんな状態か」を最初に観察する。読み取り専用 tool で状況把握 → その後本タスクに入ると失敗率激減。
