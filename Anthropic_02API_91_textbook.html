① コース02 全体マップ

コース02「Claude with the Anthropic API」では、Claude API を使いこなすために必要な要素を順番に学んだ。最後に全体を1枚で整理する。

到達点: 「Claude を使って自分のアプリ・自動化を作れる」状態になる。

② 学んだ主要トピック (Module 別)

  1. API の基本: messages.create / model 指定 / max_tokens / system prompt
  2. マルチターン会話: messages 配列で履歴保持
  3. Tool use: スキーマ定義 → tool_use 受信 → 実行 → tool_result 返却
  4. Fine-grained streaming: 大きい tool input でも早期実行
  5. Structured output: JSON 出力の安定化
  6. RAG: 埋め込み + 検索 + 文脈注入
  7. Prompt caching: 同じ前置きで cost / latency 大幅削減
  8. Citations: 引用元の自動付与
  9. Extended thinking: 推論深度を制御
  10. Image / PDF input: マルチモーダル対応
  11. Files API: 大規模ファイルの直接アップロード
  12. Code execution / Web search / MCP: 高度な統合 tool
  13. Workflows vs Agents: 設計パターンの選択

③ 自分のアプリで使うチェックリスト

  • [ ] モデル選定 (Opus / Sonnet / Haiku) は要件に合っているか
  • [ ] System prompt で役割・制約を明示しているか
  • [ ] 長い文脈には Prompt caching を有効化したか
  • [ ] Tool use が必要なら schema 設計・終了条件を決めたか
  • [ ] Workflow / Agent どちらで実装するか判断したか
  • [ ] Rate limit / リトライ / タイムアウトを実装したか
  • [ ] コスト見積もり (token 使用量 × 単価) を確認したか

④ 次のステップ

  • コース03「Model Context Protocol (MCP)」: tool を 標準プロトコル 化して、外部サーバとして使える
  • コース04「Claude Code」: Anthropic 公式 CLI で実装そのものを Claude に任せる
  • 自分のプロジェクトで Hello World → 本格運用へ
マインドセット: 完璧なプロンプトより、まず動かしてイテレーション。実プロジェクトで触りながら覚えるのが最速。

⑤ 中学生向けまとめ

このコースは「Claude という賢いロボットの取扱説明書」だった。基本ボタン (API) → 道具を使わせる (Tool) → 速くする (Caching) → 文書を読ませる (PDF) → 自分で考えさせる (Agent) という順で覚えた。卒業おめでとう。
