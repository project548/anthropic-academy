Anthropic Academy / コース02 Claude with the Anthropic API

① このコースで学ぶこと

「Building with the Claude API」は Anthropic API を使って Claude を自前アプリに組み込む ための実践コース。Claude.ai (ブラウザ版) ではなく API レベル で Claude を操る技術を学ぶ。

カバーするモジュール:
  1. Accessing Claude with the API (#7-#17): API基礎
  2. Prompt Evaluation (#22-#29): プロンプト品質測定
  3. Prompt Engineering Techniques (#30-#36): 良いプロンプトの書き方
  4. Tool Use with Claude (#37-#49): Function calling
  5. RAG and Agentic Search (#50-#55): 検索拡張生成
  6. Features of Claude (#56-#63): 拡張機能 (caching/citations等)
  7. Model Context Protocol (#65-): MCP

② このコースで作るもの

  • Claude を呼ぶ最小プログラム (#10-#11)
  • 会話履歴を持つチャットbot (#12-#13)
  • Prompt評価フレームワーク (#22-#28)
  • Tool use エージェント (#37-#45)
  • RAG (検索+生成) システム (#50-#55)
  • 自前 MCP サーバー (#66-)
到達目標: 「Claude API を業務アプリに組み込んで価値を出せる」状態。
