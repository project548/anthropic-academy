Defining resources— MCP server で「リソース」を提供する

Anthropic Academy / コース02 Claude with the Anthropic API

① Resource って何?

MCP の3本柱 (Tools / Resources / Prompts) のうち、Resources は 「読み取り専用データ」 の提供。Tool は動詞 (実行) / Resource は名詞 (参照)。

例:
  • ファイル一覧 (file://path/)
  • DB スキーマ (db://schema/users)
  • API レスポンスのキャッシュ (api://github/repos)
  • 設定値・定数 (config://app/settings)

② FastMCP での定義

from mcp.server.fastmcp import FastMCP

mcp = FastMCP("my-server")

@mcp.resource("config://app/settings")
def get_settings() -> str:
    """アプリ設定の取得"""
    return """
    {
      "theme": "dark",
      "language": "ja",
      "max_retries": 3
    }
    """

@mcp.resource("file://docs/{name}")
def get_doc(name: str) -> str:
    """ドキュメント取得 (動的URI)"""
    with open(f"docs/{name}.md") as f:
        return f.read()

③ URI のパターン

  • 静的URI: config://app/settings (固定)
  • 動的URI: file://docs/{name} ({name} で可変)
  • スキーム自由: file/// db/// api/// config/// memo/// 等好きに命名
scheme は自由。資源の種類が分かるように命名。

④ Tool との使い分け

場面Tool / Resource
ファイル「読む」だけResource
ファイル「書く・編集」Tool
DB SELECTResource
DB INSERT/UPDATETool
API GETResource (or Tool)
API POST/PUTTool
原則: 副作用なし = Resource / 副作用あり = Tool。

⑤ 中学生向けに例えると

図書館で本を「読む」のが Resource (借りるだけ)、「書き込む」のが Tool (本に痕跡を残す)。MCP は両方区別して安全に提供する。

⑥ 理解度チェック

Q1. Tool と Resource の違いは?

Tool = 動詞・副作用あり (実行)。Resource = 名詞・副作用なし (参照)。

Q2. 動的URIの書き方は?

@mcp.resource("file://docs/{name}") のように {name} プレースホルダーを使う。関数の引数で受け取る。
