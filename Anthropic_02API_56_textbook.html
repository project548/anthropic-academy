Extended thinking— Claudeに「考える時間」を与えて、難問の精度を上げる

Anthropic Academy / コース02 Claude with the Anthropic API

① まず結論 — Extended thinkingって何?

通常 Claude は「質問を受けたらすぐ答え始める」。Extended thinking は 応答を作る前に「内部で考える時間」を与える 機能。難しい数学・コーディング・推論で精度が大幅向上する。

2段階出力:
  1. thinking ブロック: Claude が内部で「ああでもないこうでもない」と考える内容
  2. text ブロック: 最終応答

② 何が変わる?

タスク通常Extended thinking
数学・物理の難問計算ミスが多い段階的に検算する → 正確
長文の論理推論結論が飛ぶ前提を整理してから結論
コードリファクタ表層的な変更影響範囲を考慮した変更
創作・要約同じ品質大きな違いなし (オーバースペック)
注意: 全質問で thinking を有効にすべきではない。難問だけ 有効にする。簡単な質問では thinking がコスト増・速度低下のデメリットになる。

③ 最小コード — thinking を有効化

response = client.messages.create(
    model="claude-opus-4-7",
    max_tokens=16000,
    thinking={
        "type": "enabled",
        "budget_tokens": 10000  # 最大10000トークン考える
    },
    messages=[{
        "role": "user",
        "content": "100以下の素数を全部列挙して、その合計を計算して"
    }],
)

# response.content には2種類のブロックが入る
for block in response.content:
    if block.type == "thinking":
        print(f"[内部思考] {block.thinking}")
    elif block.type == "text":
        print(f"[最終応答] {block.text}")
thinking パラメータ:
  • type: "enabled" で機能ON
  • budget_tokens: 思考に使えるトークン上限 (max_tokens より小さく)

④ budget_tokens の調整目安

タスク難易度budget_tokens例
軽量 (簡単な計算)1,024〜2,000小学校算数
中程度 (推論)5,000〜10,000論理パズル・要件整理
高難度 (数学・科学)20,000〜32,000大学レベル数学・複雑コーディング
超高難度 (研究)32,000〜64,000論文レビュー・大規模リファクタ
tips: 最初は budget_tokens=10000 で試す → 出力品質と所要時間を見て調整。

⑤ thinking の中身を見る

[内部思考]
よし、100以下の素数を列挙していこう。素数は2以上で、1とそれ自身でしか割り切れない数。
- 2, 3, 5, 7 (一桁の素数)
- 11, 13, 17, 19 (10-19)
- 23, 29 (20-29)
...
合計を計算: 2+3+5+7+11+13+...
段階的に: 2+3=5, +5=10, +7=17, +11=28...

[最終応答]
100以下の素数は25個あり、合計は1060です。
核心: 通常モデルは「いきなり答え」を出す。Extended thinking は 「考えてから答える」 という人間のような振る舞いを実現。

⑥ Tool use と組み合わせ

response = client.messages.create(
    model="claude-opus-4-7",
    max_tokens=16000,
    thinking={"type": "enabled", "budget_tokens": 8000},
    tools=[{"type": "web_search_20250305", "name": "web_search"}],
    messages=[{
        "role": "user",
        "content": "最新のAI業界トレンドを3つ調べて、それぞれの相互関係を分析して"
    }],
)
応用: Extended thinking + tool use = Claude が本当に賢いエージェント として振る舞う。

⑦ コストへの影響

  • thinking トークンも output tokens としてカウントされる
  • budget_tokens=10000 なら、output 料金が +10000 トークン分
  • Claude Opus 4.7 の場合: 1万トークン ≈ 約$0.15 追加
判断軸: 「間違えたら高くつく」「再試行コストが高い」タスクで thinking を ON。チャットボットの雑談には不要。

⑧ 中学生向けに例えると

学校の例えExtended thinking の対応
テスト中「すぐ答えを書く生徒」通常モード
テスト中「下書きで計算してから清書する生徒」Extended thinking
「下書きは採点対象外、本番答えだけ採点」thinking ブロックは内部過程・text ブロックが最終応答
下書きの紙の量 = budget_tokens思考に使える上限
核心: 難問では「下書きあり」のほうが正答率が上がる。簡単な問題で下書きは要らない。タスクで使い分け。

⑩ 理解度チェック

Q1. Extended thinking が向くタスクは?

① 数学・物理の難問 (段階的検算が必要) ② 長文の論理推論 (前提整理が必要) ③ 複雑なコードリファクタ (影響範囲考慮)。逆に向かない: 雑談・短文要約・FAQ応答などシンプル質問。

Q2. thinking ブロックと text ブロックの違いは?

thinking: Claudeの内部思考 (下書き) — ユーザーに見せるか開発者判断。
text: 最終応答 — ユーザーに見せる正式回答。

Q3. budget_tokens の決め方は?

タスク難易度に応じて 1,024 (簡単) 〜 64,000 (超難問)。最初は 10,000 で試して、出力品質と所要時間を見て調整。

Q4. コストへの影響は?

thinking トークンも output tokens としてカウントされ課金。「間違えたら再試行コストが高い」タスクで使うとROIが高い。雑談には不要。
