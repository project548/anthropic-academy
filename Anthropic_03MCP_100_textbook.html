Implementing a client— MCP クライアントを自前実装する

Anthropic Academy / コース03 Model Context Protocol

① なぜ自前クライアントを作る?

Claude Desktop / Claude Code は既製の MCP クライアント。でも 自分のアプリ に MCP server を組み込みたいときは、自前で MCP Client SDK を使ってクライアント実装する。

ユースケース: 自社の社内ツール / Slack Bot / Web アプリ等から、複数の MCP server を呼び出す統合層を作る場面。

② Python MCP Client SDK

from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

async def main():
    # サーバ起動パラメータ
    server_params = StdioServerParameters(
        command="python",
        args=["my_server.py"],
        env={"API_KEY": "xxx"}  # 環境変数渡し可能
    )

    # サーバを spawn して接続
    async with stdio_client(server_params) as (read, write):
        async with ClientSession(read, write) as session:
            # 初期化 (capabilities 交換)
            await session.initialize()

            # tool 一覧取得
            tools = await session.list_tools()
            for t in tools.tools:
                print(f"{t.name}: {t.description}")

            # tool 呼び出し
            result = await session.call_tool(
                "get_weather",
                arguments={"city": "Tokyo"}
            )
            for content in result.content:
                print(content.text)

③ Client SDK の主要メソッド

  • session.initialize(): 接続初期化 (必須)
  • session.list_tools(): server から tool 一覧取得
  • session.call_tool(name, arguments): tool 実行
  • session.list_resources(): resource 一覧取得
  • session.read_resource(uri): resource 内容を取得
  • session.list_prompts(): prompt 一覧取得
  • session.get_prompt(name, arguments): prompt を取得

④ Claude API と組み合わせる例

import anthropic
from mcp import ClientSession, StdioServerParameters

async def claude_with_mcp(user_message: str):
    # 1. MCP server 接続
    params = StdioServerParameters(command="python", args=["server.py"])
    async with stdio_client(params) as (r, w):
        async with ClientSession(r, w) as session:
            await session.initialize()

            # 2. MCP の tool 一覧を Claude API 形式に変換
            mcp_tools = await session.list_tools()
            claude_tools = [{
                "name": t.name,
                "description": t.description,
                "input_schema": t.inputSchema
            } for t in mcp_tools.tools]

            # 3. Claude API 呼び出し
            client = anthropic.Anthropic()
            messages = [{"role": "user", "content": user_message}]

            while True:
                response = client.messages.create(
                    model="claude-opus-4-7",
                    max_tokens=4096,
                    tools=claude_tools,
                    messages=messages
                )
                messages.append({"role": "assistant", "content": response.content})

                if response.stop_reason != "tool_use":
                    return response.content[0].text

                # 4. tool_use を MCP server で実行
                tool_results = []
                for block in response.content:
                    if block.type == "tool_use":
                        result = await session.call_tool(block.name, block.input)
                        tool_results.append({
                            "type": "tool_result",
                            "tool_use_id": block.id,
                            "content": result.content[0].text
                        })
                messages.append({"role": "user", "content": tool_results})

⑤ 接続方式 (Transport)

  • stdio: ローカル子プロセス起動 + 標準入出力 (最も簡単)
  • HTTP + SSE: リモート server 接続 (Server-Sent Events)
  • WebSocket: 双方向通信 (一部実装)

自社サーバとして MCP を運用する場合は HTTP + SSE 推奨。Python は sse_client を使う。

⑥ エラーハンドリング

  • session.initialize() 失敗 → server 起動エラー / プロトコル不一致
  • call_tool エラー → server 内例外がそのまま伝搬
  • 接続断 → async with ブロックで自動 cleanup
  • タイムアウト → ClientSession に timeout 引数を渡す

⑦ 中学生向けに例えると

家電を自分のスマホアプリから操作する SDK を作る作業。Claude Desktop = メーカー純正アプリ。自前 client SDK = 自社が作る独自リモコンアプリ。同じ規格 (MCP) なので、どの家電 (server) でも同じ繋ぎ方で操作できる。
