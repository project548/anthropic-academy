Chaining workflows— タスクを連鎖して逐次実行する workflow パターン

Anthropic Academy / コース02 Claude with the Anthropic API

① パターン定義

Chaining = 複数のLLM呼び出しを 順次接続 し、前のステップの出力を次のステップの入力にする workflow パターン。

用途: 1回の呼び出しで複雑すぎる作業を、複数の単純ステップに分解 → 各ステップは小さく確実に → 全体で複雑タスク達成。

② コード例 (3段階チェイン)

def chain_workflow(raw_text: str) -> dict:
    # Step 1: 抽出
    step1 = client.messages.create(
        model="claude-haiku-4-5",  # 軽量モデルで十分
        max_tokens=512,
        messages=[{"role": "user", "content":
            f"以下から人名・組織名・日付をJSON抽出:\n{raw_text}"
        }]
    )
    entities = parse_json(step1.content[0].text)

    # Step 2: 検証 (前のステップの出力を使う)
    step2 = client.messages.create(
        model="claude-sonnet-4-6",
        max_tokens=1024,
        messages=[{"role": "user", "content":
            f"以下のエンティティ抽出結果に欠落・誤りはないかチェック:\n"
            f"原文: {raw_text}\n抽出: {entities}"
        }]
    )

    # Step 3: 整形
    step3 = client.messages.create(
        model="claude-haiku-4-5",
        max_tokens=512,
        messages=[{"role": "user", "content":
            f"以下を整形JSONで出力:\n{step2.content[0].text}"
        }]
    )
    return parse_json(step3.content[0].text)

③ 使い所

  • 多段階処理: 翻訳 → 校正 → 整形
  • 段階的精緻化: 草案生成 → 改善 → 仕上げ
  • 各段でモデル変更: 軽量モデルで前処理 → 高精度モデルで本処理
  • Gate (関門): 各ステップで「次に進む価値あるか」判定 → 早期打切

④ Parallelization (#83) との違い

  • Parallel: 独立タスク並列実行 (各 Claude は他を知らない)
  • Chaining: 依存タスク逐次実行 (後段は前段の結果を使う)
2つを 組合せ るパターンも多い。例: 「並列で5観点レビュー → チェインで結果統合 → 最終報告」。

⑤ 中学生向けに例えると

工場ライン。Step1 で部品作成 → Step2 で組立 → Step3 で検査 → Step4 で梱包。各工程は前の出力を受け取って次に渡す。
