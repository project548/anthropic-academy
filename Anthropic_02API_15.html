① 一言まとめ
この演習ではシステムプロンプトをコードで実装するスキルを身につける。 数学チューター・カスタマーサポートなど特定の役割をClaudeに与えることで、 応答のスタイルや振る舞いを制御できることを実際に確かめる。
② キーポイント
  • 1
    system引数で渡す
    client.messages.create() に system キーワード引数として文字列を渡すだけで実装できる。 messagesリストとは別に設定するのがポイント。
    response = client.messages.create( model=model, max_tokens=1000, system="You are a patient math tutor. Give hints, not answers.", messages=[{"role": "user", "content": "What is 12 × 8?"}] )
  • 2
    役割 → 行動指示の2段構成
    効果的なシステムプロンプトは「あなたは〇〇です」という役割付与と、 「〜してください／〜しないでください」という行動指示の2段構成になっている。
    You are a patient math tutor. - Give hints instead of direct answers - Encourage students to think through problems - Use simple language appropriate for high school level
  • 3
    Noneの場合の条件分岐
    システムプロンプトが不要なケースも考慮し、None のときは system キーを辞書に含めないのがベストプラクティス。
    def chat(messages, system_prompt=None): params = { "model": model, "max_tokens": 1000, "messages": messages } if system_prompt: params["system"] = system_prompt return client.messages.create(**params)
  • 4
    「何を答えるか」でなく「どう答えるか」を制御
    システムプロンプトはコンテンツではなく応答スタイルを変える。 同じ質問でも役割が違えば回答の形式・言葉遣い・深さが変わる。
    ℹ️ 例：「12×8は？」に対して、数学チューターは直答を避けてヒントを出す。一般的なアシスタントは即座に「96」と答える。
  • 5
    **アンパック演算子でparams渡し
    **params を使うことで辞書のキーをそのままキーワード引数として展開できる。 systemの有無でif分岐した辞書を柔軟に渡すのに便利なPythonの文法。
    ✅ この書き方はAPI呼び出しをラップするヘルパー関数でよく使われるパターン。覚えておくと汎用的に使える。
③ 実装ステップ
1
役割を決める

どんな専門家・キャラクターをClaudeに演じさせるかを明確にする。例：「忍耐強い数学チューター」「フレンドリーなカスタマーサポート担当者」

2
システムプロンプト文字列を作成

1行目に役割を宣言し、続けて具体的な行動ルールを箇条書きで追加する。「〜しないでください」より「〜してください」という肯定形が明確。

3
chat関数にsystem_promptパラメーターを追加

params 辞書を使い、system_prompt が None でなければ system キーを追加する。

4
ビフォー/アフターで比較する

同じ質問をシステムプロンプトあり・なしで送り、応答の違いを確認する。役割が正しく機能しているかを検証する。

5
マルチターン会話でも維持されるか確認

システムプロンプトは会話全体を通じて有効。複数回やり取りしても役割が一貫して保たれることを確かめる。

⚠️ システムプロンプトをmessagesリストの中に入れないこと。必ず別の system 引数として渡す。
④ 用語集（初心者向け解説）
システムプロンプト
AIに「あなたはこういう役を演じてください」と事前に指示する特別なメッセージ。ユーザーには見えない裏側の設定。
system引数
messages.create() に渡すキーワード引数。messagesとは別に、モデルの振る舞いを定義するテキストを渡す場所。
**アンパック
Pythonの文法で、辞書 {"a": 1, "b": 2} を func(**d) のように関数の引数として展開する記法。
ロールプレイ（役割付与）
AIに特定のキャラクターや専門家を演じさせること。システムプロンプトの主な使い方のひとつ。
マルチターン会話
ユーザーとAIが複数回やり取りする会話形式。システムプロンプトは全ターンを通じて有効。
params辞書
API呼び出しのパラメーターをまとめた辞書。条件によって中身を変えてから **params で展開するパターンがよく使われる。
⑤ 理解度チェック
Q1
システムプロンプトをAPIに渡すとき、どこに記述しますか？
答えを見る
client.messages.create() の system キーワード引数として渡す。messagesリストの中には入れない。system="あなたは数学チューターです" のように文字列で渡す。
Q2
システムプロンプトが None のときに system キーを辞書に含めない実装をするのはなぜですか？
答えを見る
APIに空の system 値を渡すとエラーや予期しない動作の原因になる可能性があるため。if system_prompt: で条件分岐し、値がある場合のみ params["system"] に追加することで安全に処理できる。
Q3
数学チューターのシステムプロンプトを設定したとき、「12×8は？」という質問に対してClaudeはどう応答することが期待されますか？
答えを見る
直接「96」とは答えず、生徒が自分で考えられるようにヒントを与える形で応答する。例：「12を10と2に分けて考えてみましょう。10×8はいくつですか？」のように問いかけ、思考を促す。
