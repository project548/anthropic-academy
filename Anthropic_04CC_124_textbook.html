Another useful hook— 「Claude が tool 使用前にチェック」する hook 実装

Anthropic Academy / コース04 Claude Code

① 今回の hook の目的

Claude が Bash コマンドを実行する直前に、コマンド内容を 解析・分類して、特定パターンなら警告 or ログ記録する hook を作る。

シナリオ: 「git push に commit メッセージが含まれてない」「テスト未実行で deploy しようとしてる」など、業務固有のチェックを自動で挟む。

② 実装: PreToolUse hook

# .claude/hooks/pre-bash-check.js
const fs = require('fs');

let data = '';
process.stdin.on('data', chunk => data += chunk);
process.stdin.on('end', () => {
  const input = JSON.parse(data);
  const cmd = input.tool_input?.command || '';

  // ① ログ記録
  fs.appendFileSync(
    require('os').homedir() + '/.claude/logs/bash-history.log',
    `[${new Date().toISOString()}] ${cmd}\n`
  );

  // ② deploy 前の安全チェック
  if (/deploy|kubectl\s+apply|terraform\s+apply/i.test(cmd)) {
    console.error('⚠️  Deploy 系コマンド検出。事前テスト確認を推奨');
    // process.exit(2) でブロックも可能
  }

  // ③ git push 警告
  if (/git\s+push.*--force/i.test(cmd)) {
    console.error('⚠️  force push 検出。本当に必要か再確認');
    process.exit(2);  // ブロック
  }

  // 通常は素通り
  console.log(data);
  process.exit(0);
});

③ settings.json への登録

{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "blocking": true,
        "command": "node $CLAUDE_PROJECT_DIR/.claude/hooks/pre-bash-check.js",
        "description": "Bash 実行前のチェック・ログ"
      }
    ]
  }
}

④ 入出力フォーマット

  • stdin: tool 呼び出しの JSON ({"tool_name", "tool_input"})
  • stdout: そのまま流す = tool 続行 / 改変 = Claude への返却に影響
  • stderr: ユーザーターミナルに表示 (ブロック時のメッセージに使う)
  • exit 0: 続行 / exit 2: ブロック

⑤ 応用パターン

  • 業務時間チェック: 夜間の自動 deploy をブロック
  • ブランチチェック: main 直接 push をブロック
  • 環境変数検証: 本番 DB URL が誤って使われていないか
  • ファイル名パターン: .env.production 編集時に警告
  • テスト未実行 deploy: 直近の test 実行履歴をチェック

⑥ 注意点

  • blocking hook は 速さ重要: 遅いと毎回数秒待たされる
  • process.exit(2) はストレスの元 → 本当に危険な場合のみ
  • 警告 (stderr) で済むなら exit 0 のまま
  • ログだけ取って判断は人間任せ、というスタイルも有効

⑦ 中学生向けに例えると

家のドアに「外出する時のチェックリスト」を貼っておく感じ。「鍵閉めた?」「火元 OK?」「エアコン消した?」を出る直前に自動表示。Claude Code でも「危なそうな操作の前」にこういうチェックを挟める。
