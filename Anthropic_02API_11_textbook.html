リクエストを行う— Claude API の最小1リクエスト

Anthropic Academy / コース02 Claude with the Anthropic API

① 最小コード — 7行で動く

from dotenv import load_dotenv
from anthropic import Anthropic

load_dotenv()
client = Anthropic()

response = client.messages.create(
    model="claude-sonnet-4-6",
    max_tokens=1024,
    messages=[{"role": "user", "content": "こんにちは!"}]
)

print(response.content[0].text)
これでClaude が応答する。1リクエスト 約 $0.001 程度。

② 必須パラメータ3つ

  • model: 使うモデルID (例: claude-sonnet-4-6)
  • max_tokens: 応答の最大トークン数 (例: 1024)
  • messages: 会話履歴の配列。最低1つ user メッセージが必要
他のパラメータ (temperature/system/stop_sequences/tools等) はオプション。次章以降で順番に学ぶ。

③ レスポンスの構造

response = Message(
    id="msg_01XYZ...",
    type="message",
    role="assistant",
    content=[ TextBlock(type="text", text="こんにちは!お元気ですか?") ],
    model="claude-sonnet-4-6",
    stop_reason="end_turn",   # 終了理由
    usage=Usage(input_tokens=10, output_tokens=15)
)

# テキスト取得
text = response.content[0].text
content は配列。tool使用時は複数ブロック (text + tool_use) になる。

④ stop_reason の種類

  • end_turn: 通常終了 (Claudeが「もう終わり」と判断)
  • max_tokens: 上限到達で打切
  • tool_use: tool 呼び出しで一時停止
  • stop_sequence: 指定の停止語に到達

⑤ 中学生向けに例えると

「Claude宛てに手紙(messages)を書いて、最大1024文字で返事して(max_tokens)、Sonnet先生に届けて(model)」と頼む。返事(content[0].text)が返ってくる。

⑥ 理解度チェック

Q1. 必須パラメータ3つは?

model / max_tokens / messages。他はオプション。

Q2. レスポンステキストの取り出し方は?

response.content[0].text。content は配列で、tool使用時は複数ブロック (text + tool_use) になる。
