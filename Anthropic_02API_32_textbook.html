Module 8 ・ Lecture 32 ・ 解説回

Being specific— 「具体的に」言う (#31 より一段細かく)

Anthropic Academy / コース02 Claude with the Anthropic API

① #31 (clear/direct) との違い

#31 = 何を言うかを明確に。#32 = どう言うかを具体的に。例: 「優しく」より「友達に話すように」「中学生に教えるように」のほうが具体的。

抽象的な形容詞 (「優しく」「丁寧に」) は 解釈の余地 がある。具体例・数値・名詞で縛る。

② Before / After 例

# ❌ 抽象的
"短く要約して"
# Claude: "短く" = 30字? 100字? 5行?

# ✅ 具体的
"100文字以内、3つの箇条書きで要約して"

# ❌ 抽象的
"親しみやすいトーンで"

# ✅ 具体的
"中学生の友達に LINE で話しかけるようなトーン (例: 『○○だよね』『〜じゃない?』)"

③ 具体化の3軸

  1. 数値: 「短く」→「100字」「3行」「5項目」
  2. 例示: 「親しみやすい」→「『〜だよね』『〜じゃない?』のような口調」
  3. 反例: 「フォーマルに」→「丁寧語使用、敬称付き。タメ口・絵文字は使わない」

④ 数値の威力

# 数値あり: Claude が「上限」「下限」を意識する
"5つの長所と3つの短所を箇条書きで"
"500文字以内"
"スコア 1-10 で評価"
"3段階で説明 (概要→詳細→例示)"

# 数値なし: Claude が好き勝手に調整 → 結果がバラつく
"長所と短所を教えて"
"短く"

⑤ 中学生向けに例えると

料理を頼むとき「美味しく作って」より「塩は5g、火は中火、3分焼いて」のほうが望む味になる。Claude も同じ。

⑥ 理解度チェック

Q1. 具体化の3軸は?

① 数値 ② 例示 ③ 反例 (「○○しない」明示)

Q2. 「優しく」を具体化すると?

「中学生の友達に LINE で話しかけるトーン (例: 『○○だよね』)」のように、ターゲットとサンプルを示す。
