Being clear and direct— 「明確かつ直接的に」指示する

Anthropic Academy / コース02 Claude with the Anthropic API

① 原則の核心

Claude に 「何をやってほしいか」を曖昧さなく書く。人間の同僚に指示するときと同じ。曖昧 = 結果も曖昧。

核心: 「察してくれ」NG。Claude は書かれた通りに動く。何も書かれていないなら何もしない (または推測で勝手な方向に行く)。

② Before / After 例

# ❌ 曖昧
"Anthropic について教えて"
→ 何を? どこまで? 何字で? どんなトーンで?

# ✅ 明確
"Anthropic 社の設立年・本社・主力製品・従業員数を箇条書きで300字以内で教えて。
ビジネス記者向けのトーンで。"
→ 完璧

③ 5つのチェックポイント

  1. 目的: 何のために (why)
  2. 内容: 何を (what)
  3. 形式: どう出力 (箇条書き / JSON / 文章)
  4. 長さ: どれくらい (300字 / 5項目)
  5. トーン: どんな雰囲気 (フォーマル / カジュアル / 子供向け)

④ 否定形より肯定形

# ❌ 否定形が多い
"絵文字を使わないで、長すぎず、専門用語を避けて、敬語じゃなくて..."
# Claude は「使わない」「避ける」より「使う」「採用する」を理解しやすい

# ✅ 肯定形
"プレーンテキストで、200字以内、平易な日本語で、カジュアルなタメ口で"

⑤ 理解度チェック

Q1. 「明確」の5要素は?

目的・内容・形式・長さ・トーン

Q2. 否定形と肯定形どちらが効果的?

肯定形。「○○しない」より「△△する」が効きやすい。
