② 問題セット (10問)

Q1. Claude Code をインストールするコマンドは?

A. npm install -g @anthropic-ai/claude-code。グローバルインストール推奨。

Q2. プロジェクト固有のルールを Claude に毎セッション読ませる方法は?

A. プロジェクトルートに CLAUDE.md を置く。毎セッションで自動読込される。

Q3. /init コマンドの役割は?

A. Claude がプロジェクトを分析して CLAUDE.md の雛形を自動生成する。

Q4. ファイル添付の記号は?

A. @。例: @src/auth.ts でファイル / @docs/ でディレクトリを context に追加。

Q5. context が膨らんだ時に圧縮するコマンドは?

A. /compact。過去履歴を Claude 自身が要約 → 圧縮版を保持。/clear は完全クリア。

Q6. 自分専用 slash command の作成場所は?

A. プロジェクト用: {project}/.claude/commands/*.md / 個人用: ~/.claude/commands/*.md。ファイル名 = コマンド名。

Q7. MCP server を Claude Code に追加するコマンドは?

A. claude mcp add <name> --command "<cmd>" --args "<args>"。一覧確認は claude mcp list。

Q8. Hook の主要なイベントは?

A. PreToolUse (tool 直前) / PostToolUse (tool 直後) / UserPromptSubmit (入力直後) / Stop (セッション終了) / SessionStart。

Q9. Hook 内で tool 実行をブロックする方法は?

A. blocking: true 設定 + スクリプトで process.exit(2)。exit 0 は通過、exit 2 は中止。

Q10. Claude Code SDK で本番運用厳禁の設定は?

A. permissionMode: "bypassPermissions"。検証用のみ・本番では allowedTools で必要最小限に絞る。
