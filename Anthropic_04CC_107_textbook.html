Introduction— コース04「Claude Code」のオリエンテーション

Anthropic Academy / コース04 Claude Code

① 講師から自己紹介

Anthropic 教育チームの講師が自己紹介する回。コース02/03 を担当した同じ講師陣で、コース04 では Claude Code を実際にターミナルで動かしながら学んでいく。

学習スタイル: 「見て真似する」が基本。各章で実際のターミナル操作画面を見ながら、自分の手元でも同じことをする。

② 受講前の準備

  • OS: macOS / Linux / Windows (WSL推奨) / 生 Windows も対応
  • Node.js: 18+ (Claude Code は Node ベース)
  • Anthropic API key または Claude Pro/Max サブスクリプション
  • git 基本操作の知識
  • ターミナル操作 に抵抗がないこと

③ コース全体マップ

  1. 導入: What is a coding assistant? / 実演 (#107-#109)
  2. セットアップ: install / プロジェクト初期化 (#110-#111)
  3. 基本操作: context / 編集 / 制御 (#112-#115)
  4. 応用: Custom commands / MCP 連携 (#116-#117)

④ 重要なマインドセット

  • 「自然言語が新しいプログラミング言語」: コマンドを暗記しなくていい
  • 「Claude に任せる」と「Claude を監督する」のバランス: 任せすぎず・口出しすぎず
  • 「diff を必ず読む」: Claude の出力を盲信せず差分を確認
  • 「失敗から学ばせる」: 出力が違ったら何が違うか伝えて再生成

⑤ コース04 で得られるもの

  • 1人で 2-3 人分の開発スピード
  • 新しい言語・フレームワークの学習コスト激減
  • レガシーコード読解の時短
  • テスト自動生成・refactoring の安定化
  • 自分専用の slash commands で「個人最適化」

⑥ 中学生向けに例えると

新しい教科の最初のオリエンテーション。「これからこういう順序で学びますよ」「準備はこれ」「マインドセットはこれ」を確認する回。次の章から本格的に手を動かす。
