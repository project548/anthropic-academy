Quiz on features of Claude— Claude の主要機能 (RAG / Caching / Citations 等) のテスト

Anthropic Academy / コース02 Claude with the Anthropic API

① 範囲・取り組み方

#50〜#63 で学んだ「Claude の features (RAG / Embeddings / Caching / Extended thinking / Citations 等)」を総点検する Quiz 回。10問中 8問正解で実務レベル。

カバー領域: Embeddings / RAG / Prompt caching / Extended thinking / Citations / Image input / PDF input / Files API。

② 問題セット

Q1. Embeddings とは?

A. テキストを 高次元ベクトル に変換したもの。意味的に近いテキストは近い位置に配置される。Voyage AI voyage-3-large 等を使用。

Q2. RAG の5ステップは?

A. ① ドキュメントを embedding 化 → ② Vector DB に保存 → ③ query を embedding 化 → ④ 類似度検索で関連チャンク抽出 → ⑤ context に注入して Claude に質問。

Q3. Prompt caching の効果は?

A. 同じ前置きを再利用 → 入力トークン課金 最大 90% 削減・latency 大幅短縮。cache_control: {type: "ephemeral"} でブロックをマーク。

Q4. Prompt caching のキャッシュ TTL は?

A. デフォルト 5分。extended 設定で 1時間まで延長可能。

Q5. Extended thinking はいつ有効化する?

A. 複雑な推論・数学・計画立案が必要なとき。thinking: {type:"enabled", budget_tokens: 16000}。simple tasks では不要。

Q6. Citations 機能は何を返す?

A. Claude が参照した document の どの範囲を引用したか。出典明示が必要な業務 (法務・リサーチ) で必須。document ブロックに citations: {enabled: true} を設定。

Q7. Image input のサポート形式は?

A. JPEG / PNG / GIF / WebP。base64 エンコード or URL 指定。{"type":"image","source":{"type":"base64","media_type":"image/png","data":"..."}}。

Q8. PDF input の制限は?

A. 最大 100ページ / 32MB。それ以上は Files API で事前アップロード。

Q9. Files API の用途は?

A. 大きいファイル (PDF / 画像 / データ) を 事前アップロードして file_id で参照。messages に毎回貼らなくて済む。

Q10. Code execution tool は何ができる?

A. Claude が Python コードを直接実行して結果を取得 (Anthropic 提供のサンドボックス)。データ分析・グラフ生成・計算で威力。
