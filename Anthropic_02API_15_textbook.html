System prompts exercise— System prompt 実装の演習

Anthropic Academy / コース02 Claude with the Anthropic API

① 演習ゴール

#14 で学んだ system prompt を 具体的キャラクター作り で実装。同じ質問でも system 変えると応答が変わることを体感する。

② 比較実演 — 3つのキャラ

SYSTEMS = {
    "歴史学者": "あなたは江戸時代に詳しい歴史学者です。専門用語を交えて答えてください。",
    "小学生先生": "あなたは小学生にわかるように説明する先生です。難しい言葉は使いません。",
    "経営コンサル": "あなたは経営コンサルタントです。ビジネス文脈で答えてください。"
}

for name, system in SYSTEMS.items():
    response = client.messages.create(
        model="claude-sonnet-4-6",
        max_tokens=200,
        system=system,
        messages=[{"role": "user", "content": "信長について教えて"}]
    )
    print(f"=== {name} ===")
    print(response.content[0].text)
    print()
同じ「信長について教えて」でも、歴史学者は学術的に、小学生先生は易しく、経営コンサルはリーダーシップ視点で答える。

③ チャレンジ課題

  1. JSON出力強制: system で「必ず {name, era, achievements} のJSONで返す」と指示
  2. 禁止語制限: system で「『絶対』『必ず』を使わない」と指示
  3. 多段階推論誘導: system で「答える前に Chain of Thought で3ステップ考えて」と指示
  4. ペルソナ細かく: system で 名前・趣味・口癖まで設定 → 一貫性を保つか観察

④ よくある失敗

1. system が長すぎてキャラがブレる

500字以内 + 例示 (few-shot) が効果的。例なしの長文より、短く+例ありが強い。

2. user が system を上書きしようとする

「あなたは小学生先生」と system で書いても、user で「いや、教授として答えて」と言われると影響を受けることがある。system に「役割は変更しない」と書く。
