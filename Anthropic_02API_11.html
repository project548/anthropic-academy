① 一言まとめ

Pythonで anthropic パッケージをインストールし、.env でAPIキーを管理したら、client.messages.create() の3パラメータでClaudeにリクエストを送れる。レスポンスは message.content[0].text で取得。

② 環境セットアップ

① パッケージインストール
%pip install anthropic python-dotenv
② .env ファイルにAPIキーを保存
ANTHROPIC_API_KEY="your-api-key-here"
③ 環境変数を読み込みクライアント作成
from dotenv import load_dotenv
load_dotenv()

from anthropic import Anthropic

client = Anthropic()
model = "claude-sonnet-4-0"
⚠ .env は必ず .gitignore に追記してバージョン管理から除外すること。

③ messages.create() の3必須パラメータ

パラメータ説明補足
model使用するClaudeモデル名例: claude-sonnet-4-0
max_tokensレスポンスの最大トークン数（安全制限）目標値ではなく上限。Claudeは適切な長さで停止する
messages会話履歴のリストrole（user/assistant）とcontentの辞書

④ はじめてのリクエスト例

message = client.messages.create(
    model=model,
    max_tokens=1000,
    messages=[
        {
            "role": "user",
            "content": "What is quantum computing? Answer in one sentence"
        }
    ]
)

# レスポンステキストの取得
print(message.content[0].text)

⑤ メッセージの構造

  • userメッセージ：Claudeに送る内容（人間が作成）
  • assistantメッセージ：Claudeが生成した応答
  • 各メッセージは role（"user" or "assistant"）と content（テキスト）の辞書
  • 会話を続けるには両方のメッセージを配列に積み重ねていく

⑥ 用語集

messages.create()
Anthropic APIへのリクエストを行う中心的な関数
max_tokens
生成の上限。Claudeはこの値に達したら停止するが、目標値ではない
message.content[0].text
レスポンスから生成テキストを取り出す方法
.env ファイル
APIキーなどの機密情報をコードから分離して管理するファイル
python-dotenv
.envファイルの内容を環境変数として読み込むパッケージ
role
メッセージの送り主。"user"（人間）か"assistant"（Claude）
