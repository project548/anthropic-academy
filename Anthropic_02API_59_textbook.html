Citations— Claudeに「どこ書いてあった?」を機械的に返させる引用機能

Anthropic Academy / コース02 Claude with the Anthropic API

① まず結論 — Citations って何?

Claude が 「答えの根拠になった文書の場所」を自動で返す 機能。RAGや文書要約で「この情報の出所は?」を機械的に検証できる。

仕組み: document ブロックに citations: {enabled: true} を付けて投げる → Claude が応答テキストの各部分に cited_text と source location を自動付与。

② なぜ重要? — 4つの理由

  • 幻覚抑制: Claude が「文書になかった内容」を答えにくくなる
  • 検証可能性: ユーザーが「どの段落の何行目?」を即確認できる
  • 法的安全: 法務・医療・金融で出典必須の現場で必須機能
  • 信頼性: AI生成と引用を区別できる → Perplexity 風UX
web_search tool (#48) の citation と同じコンセプトだが、こちらは あなたが渡した文書 に対する引用。

③ 最小コード — Citations を有効化

response = client.messages.create(
    model="claude-opus-4-7",
    max_tokens=1024,
    messages=[{
        "role": "user",
        "content": [
            {
                "type": "document",
                "source": {
                    "type": "text",
                    "media_type": "text/plain",
                    "data": "Anthropic は2021年に設立された AI 企業。本社はサンフランシスコ。Claude シリーズを開発している。"
                },
                "title": "Anthropic 会社概要",
                "context": "公式IR資料より",
                "citations": {"enabled": True}  # ← これ!
            },
            {"type": "text", "text": "Anthropic はいつ設立?"}
        ],
    }],
)

for block in response.content:
    if block.type == "text":
        print(block.text)
        if block.citations:
            for c in block.citations:
                print(f"  [引用] {c.cited_text} (from {c.document_title})")

⑤ 応答の構造 — citation はどう返ってくる

{
  "content": [
    {"type": "text", "text": "Anthropic は", "citations": null},
    {
      "type": "text",
      "text": "2021年に設立された",
      "citations": [{
        "type": "char_location",
        "cited_text": "Anthropic は2021年に設立された",
        "document_index": 0,
        "document_title": "Anthropic 会社概要",
        "start_char_index": 0,
        "end_char_index": 19
      }]
    },
    {"type": "text", "text": " AI企業です。", "citations": null}
  ]
}
核心: 応答が 細かいtext block に分かれて、引用部分だけに citations 配列が付く。UI側ではこれを マーカー/ハイライト で可視化する。

⑦ UI実装パターン — Perplexity 風

# React の例 (擬似コード)
function MessageWithCitations({ blocks }) {
  return (
    <div>
      {blocks.map((block, i) =>
        block.citations
          ? <mark
              key={i}
              data-tooltip={block.citations[0].cited_text}
              data-source={block.citations[0].document_title}
            >{block.text}</mark>
          : <span key={i}>{block.text}</span>
      )}
    </div>
  );
}
UX設計:
  • 引用部分を 下線 / 色変え でマーキング
  • ホバーで 出典文書名 + 該当箇所 をツールチップ表示
  • クリックで 元文書の該当ページ にジャンプ (PDFビューア)

⑧ コスト

  • citation を有効にしても 追加トークン料金は発生しない
  • cited_text・title・url・location は 無料 (input/output tokensにカウントしない)
  • つまり citations: enabled は 付けない理由がない → RAG/PDF処理ではデフォルトON推奨
これ重要: Anthropic は citation を 無料 にしている。法的・倫理的に出典明示が望ましいから。

⑨ よくある使い方

RAG + Citations

RAGの search 結果を type="document" + citations: enabled で投げる → Claudeの応答に「どの chunk を根拠にしたか」が自動付与される。ユーザー画面では引用元のリンクと該当箇所をマーキング表示。

長文要約 + Citations

100ページPDFを要約させるとき、citation を有効にしておけば「要約の各文が原文の何ページに対応するか」が分かる。要約の質チェック・原文確認に便利。

法務QA + Citations

「契約書のこの条項についてどう解釈?」と聞いて、Claudeの回答に どの条項を引用したか が表示される。法的に「AIが言ったから」では済まない場面で、原文出典の明示は必須。

⑩ 中学生向けに例えると

学校の例えcitations の対応
レポートで「p.12 を参考に...」と引用元を書くcitation 付き応答
引用なしのレポートは0点citation なしの回答は信頼度低
「教科書のどこに書いてあった?」と先生が確認start_char_index / page_number
引用は短く・原文ママ・出典明示cited_text + document_title
核心: AI生成と引用を明確に区別。「AIが言った」と「資料に書いてあった」を分ける ことで、ユーザーが情報の信頼性を判断できる。

⑫ 理解度チェック

Q1. Citations の主な効果は?

① 幻覚抑制 (Claudeが資料外を答えにくくなる) ② 検証可能性 (ユーザーが出典を確認できる) ③ 法的安全 (出典必須の現場で必要) ④ 信頼性向上 (AI生成と引用の区別)

Q2. どう有効化する?

document ブロックに "citations": {"enabled": true} を追加するだけ。あとは Claude が自動的に応答テキストに引用情報を埋め込む。

Q3. citation 部分のトークン料金は?

無料。cited_text・title・location は input/output tokens にカウントされない。→ RAG/PDF処理では citations: enabled を デフォルトON 推奨。

Q4. 3つの location 型の使い分けは?

char_location: テキスト文書 (文字位置)
page_location: PDF (ページ位置)
content_block_location: 構造化custom content (block index)
→ Claude が source type に応じて自動選択。
