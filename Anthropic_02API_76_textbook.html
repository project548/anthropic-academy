② セルフチェック (頻出ポイント)

Q: MCP の目的は?

AI アプリと外部システムをつなぐ オープン規格。1サーバー作れば複数AIから使い回せる。

Q: Host・Client・Server の関係は?

Host (アプリ全体) ⊃ Client (1サーバー専属接続) ⇄ Server (外部システム公開)

Q: 3本柱は何?

Tools (動詞・実行) / Resources (名詞・参照) / Prompts (テンプレ)

Q: Tool 定義のデコレータは?

@mcp.tool()。type hints + docstring から JSON schema 自動生成。

Q: サーバー実装したら最初にやるテストは?

MCP Inspector (uv run mcp dev main.py)。Claude Desktop 登録前に動作確認。

Q: クライアントが server に問い合わせる主な6リクエストは?

initialize / tools/list / tools/call / resources/list / resources/read / prompts/list / prompts/get

Q: transport の3種は?

stdio (ローカル) / HTTP+SSE (旧版リモート) / Streamable HTTP (新版・推奨)

Q: tool テスト前に Claude に接続するのは?

NG。MCP Inspector で先にテストする。「Testing isn't needed」「Connect immediately」「Test in production」は誤り。Use the MCP Inspector in your browser が正解。
