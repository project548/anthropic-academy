Defining prompts— MCP の Prompts (テンプレ) を定義する

Anthropic Academy / コース03 Model Context Protocol

① Prompts とは?

MCP の Prompts は 「再利用可能なプロンプトテンプレート」。ユーザーが Claude Desktop 上で「定型のお願い」をワンクリックで呼び出せるようにする。Tools (動詞) / Resources (名詞) と並ぶ MCP 3 Pillars の第3要素。

核心: 「いつも同じ質問の仕方をする業務」をテンプレ化 → ユーザーが手書きで毎回打たなくて済む。組織内で共有もできる。

② Tool / Resource / Prompt の違い

  • Tool: 動詞 (LLM が呼ぶ・副作用あり)
  • Resource: 名詞 (LLM が読む・副作用なし)
  • Prompt: テンプレ (ユーザーが選ぶ・LLM への指示文を組立)

③ FastMCP での定義例

from mcp.server.fastmcp import FastMCP

mcp = FastMCP("review-server")

@mcp.prompt()
def code_review(code: str, language: str = "Python") -> str:
    """コードレビュー用の定型プロンプト"""
    return f"""以下の {language} コードを次の3観点でレビューしてください:
1. バグの可能性
2. パフォーマンスの問題
3. 可読性

コード:
{code}
"""

@mcp.prompt()
def daily_standup(yesterday: str, today: str) -> str:
    """朝会報告テンプレ"""
    return f"昨日: {yesterday}\n今日: {today}\nブロッカー: なし"

関数の戻り値がそのまま「LLM に渡すプロンプト本文」になる。引数はユーザーが入力。

④ Claude Desktop での使われ方

  1. ユーザーが Claude Desktop で / を入力
  2. 登録済み prompt 一覧がサジェスト表示
  3. 選択 → 引数入力フォームが出る
  4. 送信 → テンプレに値が埋め込まれて LLM に送信
例: ユーザーは /code_review を選んでコードを貼るだけ。長いレビュー指示文を毎回手書きしなくていい。

⑤ 複雑な prompt の例 (Multi-message)

from mcp.server.fastmcp import FastMCP
from mcp.types import PromptMessage, TextContent

@mcp.prompt()
def debug_with_context(error: str, code: str) -> list[PromptMessage]:
    """エラー + 該当コードを文脈付きで送る"""
    return [
        PromptMessage(role="user", content=TextContent(type="text", text=f"以下のエラーが出ました:\n{error}")),
        PromptMessage(role="user", content=TextContent(type="text", text=f"関連コード:\n{code}")),
        PromptMessage(role="user", content=TextContent(type="text", text="原因と修正案を3つ挙げてください"))
    ]

単純な文字列だけでなく、複数 message の sequence も返せる。

⑥ Prompts vs Slash Commands (Claude Code)

  • MCP Prompts: server 側で定義・Claude Desktop / Code 両方で使える
  • Claude Code の slash commands: ローカル .claude/commands/ に置く・Claude Code 専用

組織で共有したいテンプレは MCP Prompts、個人用は slash commands。

⑦ 中学生向けに例えると

メールアプリの「定型文」機能。「お礼メール」「報告メール」のテンプレを登録しておくと、毎回ゼロから書かなくていい。MCP Prompts も同じで、Claude への「定型お願い」を登録しておける。

⑧ 理解度チェック

Q1. Prompt は誰が呼ぶ?

A. ユーザー。LLM が自動で選ぶのは Tools。Prompts はユーザーが / から明示的に選ぶ。

Q2. FastMCP での Prompt 定義は?

A. @mcp.prompt() デコレータ + 関数。引数 = ユーザー入力 / 戻り値 = LLM へのプロンプト本文。

Q3. 複数 message を返したい時は?

A. 戻り値を list[PromptMessage] 型にする。role/content を持つメッセージ列を返せる。
