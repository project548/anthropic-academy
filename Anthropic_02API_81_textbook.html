Enhancements with MCP servers— Claude Code を MCP サーバーで強化する

Anthropic Academy / コース02 Claude with the Anthropic API

① なぜ Claude Code に MCP を足す?

Claude Code は標準で ファイル操作・Bash・Web fetch 等を持つが、それ以上の機能 (Slack送信・GitHub PR作成・社内DB検索) は MCP server を追加することで 「外付け機能」 として拡張できる。

イメージ: Claude Code 本体 = 携帯電話の本体 / MCP server = アプリ追加。インストールすればすぐ使える。

② Claude Code への MCP server 追加

# コマンドで追加
claude mcp add github npx -y @modelcontextprotocol/server-github

# 環境変数経由
claude mcp add github -e GITHUB_TOKEN=ghp_xxx -- npx -y @modelcontextprotocol/server-github

# 確認
claude mcp list

# 削除
claude mcp remove github

③ Scope (有効範囲) の使い分け

  • user (デフォルト): 自分の全プロジェクトで有効 (~/.claude/mcp.json)
  • project: このプロジェクトのみ (.claude/mcp.json)
  • system: マシン全体 (要権限)
使い分け: GitHub MCP のような汎用は user / 社内DB MCPのようなプロジェクト固有は project。

④ よく追加される MCP server 例

サーバー用途
@modelcontextprotocol/server-githubIssue/PR操作・コード検索
@modelcontextprotocol/server-slackSlack メッセージ送信
@modelcontextprotocol/server-postgresPostgreSQL 操作
@modelcontextprotocol/server-puppeteerブラウザ自動化
@modelcontextprotocol/server-filesystem指定フォルダのファイル操作 (sandboxed)

⑤ 中学生向けに例えると

iPhone本体 (Claude Code) はカメラ・電話・SMS 標準装備。App Store (MCP server エコシステム) からアプリを足すと、SNS・銀行・地図 等の追加機能が使えるようになる。
