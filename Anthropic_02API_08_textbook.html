Anthropic Academy / コース02 Claude with the Anthropic API

① 3つのモデル家族

Anthropic Claude は 3つのモデル家族 を提供。用途とコストでバランスを選ぶ。

家族特徴得意料金感
Opus最高性能複雑推論・コード・研究高 ($15/M)
Sonnetバランス本番アプリ・日常タスク中 ($3/M)
Haiku軽量・速い大量処理・チャット・分類低 ($0.80/M)
選び方: 迷ったらSonnet から始める → 「精度足りない」なら Opus へ / 「コスト高すぎ」なら Haiku へ。

② 最新バージョン (2026年5月時点)

Model ID世代用途
claude-opus-4-7Opus 4.7最高性能 (Mythos Preview)
claude-opus-4-6Opus 4.61つ前世代
claude-sonnet-4-6Sonnet 4.6本番推奨 (バランス◎)

Model ID は API リクエスト時に model="claude-opus-4-7" のように指定する。世代が新しいほど高性能 + 同等以下コスト。

③ モデル選定の判断軸

  • 精度: 難問・複雑推論 → Opus / 一般的タスク → Sonnet / 単純分類 → Haiku
  • 速度: リアルタイム応答 → Haiku / 通常 → Sonnet / 時間OK → Opus
  • コスト: 大量バッチ → Haiku / 中規模 → Sonnet / 少量・高品質 → Opus
  • Context長: 全モデル 200K tokens / Opus 4.7 は 1M tokens オプション

④ 中学生向けに例えると

家族例え
Opus東大教授 (詳しいが時間と費用かかる)
Sonnet有能な大学生 (バランス良し)
Haiku機転の利く高校生 (速い・安い)

⑤ 理解度チェック

Q1. 迷ったときの第一選択は?

Sonnet。性能・速度・コストのバランスが最も良く、本番運用の8割をカバーできる。

Q2. 大量データ処理に向くのは?

Haiku。速い・安いの組合せで、分類・要約・抽出などの単純タスクを大量処理する用途に最適。
