Implementing a hook— 実用的な hook をゼロから作る

Anthropic Academy / コース04 Claude Code

① 今回作る hook

実例として「Write/Edit 後に対象ファイルへ自動 lint を実行」する hook をゼロから作る。

到達点: Claude がファイル編集するたびに、自動で lint が走り、エラーが Claude に通知される (= 次の指示で自動修正されやすくなる)。

② 実装手順

  1. .claude/hooks/ ディレクトリ作成
  2. hook 用シェルスクリプト or Node スクリプトを書く
  3. .claude/settings.json に登録
  4. 動作確認 (matcher を一旦広めに → 動いたら絞り込み)
  5. ログ・デバッグ → 安定化

③ Step 1: スクリプト作成

# .claude/hooks/auto-lint.js
const fs = require('fs');
const path = require('path');
const { execSync } = require('child_process');

let data = '';
process.stdin.on('data', chunk => data += chunk);
process.stdin.on('end', () => {
  const input = JSON.parse(data);
  const filePath = input.tool_input?.file_path;

  if (!filePath) { process.exit(0); }
  if (!/\.(js|ts|tsx)$/.test(filePath)) { process.exit(0); }

  try {
    execSync(`npx eslint --fix "${filePath}"`, { stdio: 'inherit' });
  } catch (err) {
    console.error('Lint errors found in ' + filePath);
    process.exit(0);  // 警告だけで blocking しない
  }
});

④ Step 2: settings.json に登録

{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "command": "node $CLAUDE_PROJECT_DIR/.claude/hooks/auto-lint.js",
        "description": "編集後の自動 lint"
      }
    ]
  }
}

⑤ Step 3: 動作確認

⑥ よくある実装パターン

  • 条件付き発火: filePath の拡張子で early return
  • 非 blocking: 警告だけ表示・tool は止めない (process.exit(0))
  • blocking: エラー時に process.exit(2) で tool 停止 (危険操作防止)
  • 標準入力: tool_input は JSON で stdin に流れてくる
  • 環境変数: $CLAUDE_PROJECT_DIR でプロジェクトルート相対指定

⑦ デバッグのコツ

  • 最初は echo $FILE_PATH >> /tmp/hook.log でログだけ取る
  • stdout は Claude に渡る・stderr は人間に見える
  • process.exit(2) は tool を中止 / exit(0) は通過
  • 無限ループ注意: PostToolUse hook が内部で Edit を呼ぶと再帰
  • 遅い hook はセッションを遅くする → 軽量に

⑧ 応用アイデア

  • 編集後に自動 git add (チェックポイント作成)
  • Bash 実行時の commands をローカル DB に記録 (監査)
  • tool 入力に PII (個人情報) が含まれていたら redact
  • セッション開始時に環境変数を読み込み
  • セッション終了時に Lark Doc へ要約を保存

⑨ 中学生向けに例えると

「玄関に来客センサー」を実装する作業。① センサー本体 (script) を作る → ② 玄関に取り付ける (settings.json 登録) → ③ ドアを開けて動作確認 → ④ 動かない場合は配線 (ログ) を見て修正。Claude Code の hook も同じ手順。
