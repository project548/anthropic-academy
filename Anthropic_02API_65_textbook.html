Introducing MCP— Model Context Protocol = AI と外部システムの「USB-C 規格」

Anthropic Academy / コース02 Claude with the Anthropic API

① まず結論 — MCP って何?

MCP (Model Context Protocol) は AIアプリと外部システムをつなぐオープン規格。2024年11月に Anthropic が公開し、ChatGPT・Cursor・VS Code 等も対応する業界標準になっている。

喩え: AI 用の USB-C ポート。USB-C があれば「マウス」「キーボード」「モニター」を共通に挿せる。MCP があれば「Slack」「GitHub」「Notion」「DB」を共通に AI に挿せる。

② なぜ必要? — 自前 tool との違い

観点自前tool (#37-#48)MCP
定義場所アプリ内に直書き独立した「サーバー」として切り出し
再利用性1アプリ専用複数アプリで使い回せる
言語アプリと同じ言語縛りサーバー側は自由 (Python/Node/Go等)
運用アプリ更新時に再デプロイサーバー単体で更新可能
エコシステム—公式サーバー多数 + コミュニティ
結論: 単発tool なら自前で書く。「他のAIアプリでも使い回したい / 組織で共有したい」 なら MCP化する。

③ MCP でできること

  • エージェントが Google Calendar や Notion に接続 → パーソナルAIアシスタント化
  • Claude Code が Figma デザインから Web アプリ全体を生成
  • 社内チャットbot が 複数DB横断 でデータ分析
  • AI が Blender で3Dデザイン → 3Dプリンタで印刷
共通パターン: 「Claude + 外部システム → 業務自動化」。今までは個別実装が必要だったが、MCP で 誰かが作ったサーバーを挿すだけ。

④ 3つの登場人物

役割例責任
HostClaude Desktop / Cursorユーザーが触るアプリ全体
ClientHost 内の接続管理1サーバーと1対1で通信
ServerGitHub MCP / Slack MCP外部システムを MCP 規格で公開
核心: Host は複数のサーバーに繋がる。1サーバーごとに1 Client が立ち、独立して動く。詳細は #66 で。

⑤ 3本柱 — Tools / Resources / Prompts

概念意味例
Tools (動詞)サーバーが提供する実行アクションsend_message, create_issue, search_db
Resources (名詞)サーバーが提供する読み取り専用データファイル一覧・DBスキーマ・API応答
Prompts (テンプレ)サーバーが用意したプロンプトテンプレ「障害レポート作成」テンプレ
使い分け: Tool = やってもらう / Resource = 見せてもらう / Prompt = 借りる。MCPサーバーはこの3種を組合せて公開する。

⑥ オープン規格の意味

  • Anthropic 主導だが 仕様は公開 (modelcontextprotocol.io)
  • OpenAI ChatGPT も対応
  • Visual Studio Code / Cursor / MCPJam 等 多数のクライアント
  • サーバー実装は Python / TypeScript / Go / Rust 等多言語
意味: Anthropic 1社の囲い込みではない。業界標準 としてエコシステムが育ちつつある。「MCPサーバー1個作れば、どの AI でも動く」状態。

⑩ 理解度チェック

Q1. MCP は何の略?

Model Context Protocol。AI モデルにコンテキスト(外部システム)を繋ぐためのプロトコル。

Q2. MCP の喩えは?

AI用の USB-C 規格。1つの規格でいろんな機器が繋がる。MCP も1つのプロトコルでいろんな外部システムが繋がる。

Q3. 自前tool と MCP の主な違いは?

① 再利用性 (MCPは複数アプリで使い回せる) ② 言語自由 ③ 独立運用 ④ オープンエコシステム。自前tool は単発・閉鎖。MCP は共有・開放。

Q4. 3本柱は?

Tools (実行) / Resources (データ参照) / Prompts (テンプレ取得)。MCPサーバーはこの3種を組合せて公開する。
