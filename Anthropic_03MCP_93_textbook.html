Anthropic Academy / コース03 Model Context Protocol

① このコースで学ぶこと

このコースでは Model Context Protocol (MCP) を扱う。MCP は LLM と外部 tool / データ源 を標準化された方法で繋ぐ仕様。Anthropic が 2024年末に公開してから業界標準になりつつある。

結論: MCP = 「LLM 向けの USB-C」。tool と LLM を繋ぐ統一規格。

② コース02 (Tool use) との違い

  • コース02: tool を Python コードで直接定義 → アプリ内蔵
  • コース03 (MCP): tool を 別プロセスのサーバとして作る → どの LLM クライアントからも使える

つまり「自分専用 tool」から「みんなが使える tool」へ。

③ コース03 の流れ

  1. MCP の概念 (Host / Client / Server の3層)
  2. MCP server を Python で作る (FastMCP)
  3. tool / resource / prompt の3要素を定義
  4. Claude Desktop や Claude Code から呼ぶ
  5. 本番運用 / 認証 / デプロイ

④ 前提知識

  • Python 基本構文
  • コース02 の「Tool use」回 (#39〜#48 あたり)
  • JSON / コマンドライン操作
不安な人へ: MCP は tool use の発展形。コース02 #82 (Agents and workflows) を復習しておくとスムーズ。

⑤ 中学生向けに例えると

コース02 で「自分の家専用のリモコン」を作った。コース03 では「どのテレビ・どのエアコンでも使える標準規格リモコン」を作る。一度作れば、Claude でも他の AI でも使い回せる。
