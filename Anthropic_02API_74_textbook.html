Prompts in the client— クライアント側で prompt を取得・利用する

Anthropic Academy / コース02 Claude with the Anthropic API

① 本章の目的

#73 で prompt を 提供する側 を学んだ。本章は 使う側 。クライアント (自前アプリ / Claude Desktop) で prompt を取得して活用する方法。

② Python クライアントから取得

async with ClientSession(read, write) as session:
    await session.initialize()

    # 1. prompt 一覧取得
    prompts = await session.list_prompts()
    for p in prompts.prompts:
        print(f"- {p.name}: {p.description}")
        for arg in p.arguments:
            print(f"    arg: {arg.name} ({'必須' if arg.required else '任意'})")

    # 2. 引数を埋めて prompt を取得
    result = await session.get_prompt(
        "code_review_request",
        arguments={"file_path": "src/utils.py", "focus": "security"}
    )
    # → 穴埋め済みのテンプレが返る

    # 3. 取得した prompt を Claude API に渡す
    messages = result.messages
    response = client.messages.create(
        model="claude-opus-4-7",
        max_tokens=2048,
        messages=[{"role": m.role, "content": m.content.text} for m in messages]
    )

③ Claude Desktop での体験

Claude Desktop ではユーザーが UI 上で:

  1. 入力欄に 「/」 を打つ → コマンドメニュー出現
  2. 登録されている prompts 一覧が表示
  3. 選択 → 引数入力フォームが表示
  4. 引数を埋めて Enter → prompt が会話に挿入
  5. Claude が応答開始
体感: 「テンプレを呼ぶ → 穴埋め → Claude に投げる」が UIワンクリック で完結。
