Anthropic Academy / コース03 Model Context Protocol

① クライアントの位置づけ

MCP Client = Host (アプリ) の内部にあって、MCP Server と 1対1で通信する 部品。Host が複数の Server を使う場合は、Client が Server の数だけ存在する。

関係図: Host (1) → Client (N) → Server (N)。1 Client = 1 Server に対応する1:1関係。

③ Claude Desktop での設定例

// claude_desktop_config.json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/Users/me/Documents"]
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {"GITHUB_PERSONAL_ACCESS_TOKEN": "ghp_xxx"}
    }
  }
}

設定後、Claude Desktop を再起動するだけで Server が起動 → tool が Claude から使えるようになる。

④ Client が Server に対してやること

  1. 起動: Server プロセスを spawn (stdio or HTTP で通信)
  2. 初期化: capabilities を交換 (お互いに何ができるか確認)
  3. 一覧取得: tools/list / resources/list / prompts/list
  4. 呼び出し: LLM が tool 使用決定したら tools/call
  5. 監視: Server クラッシュ時の再起動

⑤ Client SDK で自作する場合

# Python の MCP SDK 例
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

async def main():
    server_params = StdioServerParameters(
        command="python",
        args=["my_server.py"]
    )
    async with stdio_client(server_params) as (read, write):
        async with ClientSession(read, write) as session:
            await session.initialize()
            tools = await session.list_tools()
            result = await session.call_tool("get_weather", {"city": "Tokyo"})
            print(result.content)

⑥ 中学生向けに例えると

Host = アプリ全体 = テレビ本体 / Client = リモコン本体 / Server = エアコン・電気・カーテン 各家電。リモコン (Client) は家電1台ずつに専用ボタンを持つ。テレビ (Host) は複数のリモコン (Client) を内蔵していて、家電を全部操作できる。

⑦ 理解度チェック

Q1. MCP Host と Client の違いは?

A. Host はユーザー向けアプリ全体 (Claude Desktop など)。Client は Host 内部にあって個別の Server と1対1で通信する部品。

Q2. 1つの Host が複数の Server を使う場合、Client は何個必要?

A. Server の数だけ。Client は Server と1:1関係。
