Chat exercise— Multi-Turn 実装の演習

Anthropic Academy / コース02 Claude with the Anthropic API

① 演習ゴール

#12 で学んだ multi-turn パターンを 動くチャットbot として実装する。ターミナルで対話できる最小チャットアプリ。

達成基準:
  • ユーザーが何度でも質問できる
  • Claude が過去の会話を覚えている
  • "exit" で終了

② リファレンス実装

from dotenv import load_dotenv
from anthropic import Anthropic

load_dotenv()
client = Anthropic()
messages = []

def chat(user_input):
    messages.append({"role": "user", "content": user_input})
    response = client.messages.create(
        model="claude-sonnet-4-6",
        max_tokens=1024,
        messages=messages
    )
    reply = response.content[0].text
    messages.append({"role": "assistant", "content": reply})
    return reply

print("Claude チャット (exit で終了)")
while True:
    user = input("You: ")
    if user.strip().lower() == "exit":
        break
    print("Claude:", chat(user))

③ チャレンジ課題

  1. 会話履歴の保存: JSONファイルに保存して、次回起動時に読み込む
  2. システム指示: system= パラメータで Claude の役割を設定
  3. 履歴削減: 20ターン超えたら古い10ターンを要約して圧縮
  4. ストリーミング: 応答を1文字ずつ表示

④ よくあるバグ

1. messages の role が連続

「user → user」になっていないか確認。append のタイミングを見直す。

2. 過去履歴が膨れすぎてエラー

context length 超過。古い履歴削除 or 要約圧縮。

3. 応答テキストが取れない

response.content[0].text。content は配列だが、tool使用時は他のブロックも混じる。
