② コース02 で扱う対象

本コースは Anthropic API + Claude Code がメイン。Claude.ai/Desktop はエンドユーザー向けで、コース02 のスコープ外。

この後のレクチャー (#79-#88) で Claude Code + エージェントパターン を実装ベースで学ぶ。

③ なぜ Claude Code を学ぶ?

  • API を直接呼ぶだけでなく、エージェント型のCLIツールでClaude活用を体感
  • MCP との統合 → 外部システム連携の実装例
  • workflow パターン (parallelization / chaining / routing) を実機で動かす

④ 中学生向けに例えると

Anthropic は「Claude」というキャラクターを、いろんな場所 (ブラウザ・スマホ・ターミナル・自社アプリ組込み) で使えるように複数の入り口を用意している。場面によって最適な入口が違う。
