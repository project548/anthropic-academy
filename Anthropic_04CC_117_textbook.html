MCP servers with Claude Code— Claude Code から MCP server を呼び出す

Anthropic Academy / コース04 Claude Code

① この章の位置づけ

コース03 で学んだ MCP server を、コース04 で学んだ Claude Code から実際に呼んで連携させる集大成回。

核心: Claude Code は MCP の 最大のクライアント。MCP server を登録するだけで、Claude Code から直接 tool / resource / prompt が使えるようになる。

② Claude Code に MCP server を追加

# CLI から追加 (推奨)
claude mcp add github --command "npx" --args "-y @modelcontextprotocol/server-github"

# 環境変数を渡す
claude mcp add github \
  --command "npx" \
  --args "-y @modelcontextprotocol/server-github" \
  --env "GITHUB_PERSONAL_ACCESS_TOKEN=ghp_xxx"

# 一覧確認
claude mcp list

# 削除
claude mcp remove github

③ 設定ファイルでの管理

// ~/.claude.json (個人) or プロジェクト .mcp.json
{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": { "GITHUB_PERSONAL_ACCESS_TOKEN": "ghp_xxx" }
    },
    "lark": {
      "command": "node",
      "args": ["/path/to/lark-mcp/index.js"]
    }
  }
}

④ よく使う MCP servers

  • filesystem: ローカルファイル読み書き (公式)
  • github: GitHub Issues / PR / コード検索 (公式)
  • postgres: PostgreSQL クエリ実行 (公式)
  • puppeteer / playwright: ブラウザ自動操作
  • slack / discord: チャットツール連携
  • memory: 永続的ナレッジグラフ
  • context7: 最新ライブラリドキュメント取得

⑤ Claude Code 内での使い方

# 起動して登録済み MCP server が読み込まれる
claude

# tool として呼ぶ (Claude が自動判断)
> このリポジトリの open な PR を一覧で

# Resource として参照
> @github:repo://myorg/myproject/README.md

# Prompt として呼ぶ
> /github:create_pr title="新機能" body="詳細..."

⑥ セキュリティ・権限管理

  • MCP server は 別プロセスで動く → サンドボックス化
  • 環境変数経由で認証 → ソースコードに秘密情報を入れない
  • .claude/settings.json の permissions で特定 server / tool を許可制に
  • 本番 DB アクセス系は 明示承認 設定推奨

⑦ 自作 MCP server を Claude Code で使う

# コース03 で作った自作 server を追加
claude mcp add my-server \
  --command "uv" \
  --args "--directory /path/to/my-mcp-server run server.py"

# Claude Code 内で確認
> mcp tools list
# → my-server から提供される tool 一覧が表示

⑧ 中学生向けに例えると

スマホに新しいアプリを入れる感覚。claude mcp add = アプリインストール。一度入れたら、Claude (スマホ本体) から「○○して」と言うだけで、そのアプリの機能を使える。アプリは別プロセスで動くので、Claude 本体を汚さない。
