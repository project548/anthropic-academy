MCP review— コース03 で学んだ MCP 全体の振り返り

Anthropic Academy / コース03 Model Context Protocol

① MCP の本質を1枚で

MCP = LLM 向けの USB-C 規格
どの LLM クライアントからも、どの外部 tool / データ源にも、同じ繋ぎ方でアクセスできる。Anthropic が 2024-11 にオープンソース公開し、業界標準化が進行中。

② 3層アーキテクチャ再確認

層役割例

ClientServer と1対1通信Host 内蔵 (MCP SDK)
Servertool / resource / prompt 提供GitHub MCP / 自作 server.py

④ ハンズオン全体フロー (再現手順)

  1. uv init + uv add "mcp[cli]"
  2. server.py 作成 → FastMCP("name") インスタンス化
  3. @mcp.tool() / @mcp.resource("...") / @mcp.prompt() で3 Pillars 定義
  4. uv run mcp dev server.py → MCP Inspector で動作確認
  5. claude_desktop_config.json に登録 → Claude Desktop 再起動
  6. ハンマーアイコン / @ / / でアクセス確認

⑤ コース02 (Tool use) との関係性

  • コース02: API 直書きで tool 定義 (アプリ内蔵)
  • コース03 (MCP): tool を別プロセスサーバ化 (再利用可能・標準)

同じ「tool を使わせる」でも、再利用性 / 公開性が大きく変わる。組織内共有や OSS 公開には MCP が向く。

⑥ 実務でよくある選択

  • 自分1人で使う簡易 tool → コース02 直書きで十分
  • チーム / 組織で共有 → MCP server 化
  • 外部公開・OSS → MCP + npm/PyPI で配布
  • 業界標準を作りたい → MCP (例: GitHub MCP / Slack MCP)
