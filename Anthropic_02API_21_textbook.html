Quiz on accessing Claude with the API— API で Claude にアクセスする基本知識テスト

Anthropic Academy / コース02 Claude with the Anthropic API

① 範囲・取り組み方

#5〜#20 で学んだ「API の基本アクセス」を総点検する Quiz 回。10問中 8問正解で実務レベル。

カバー領域: API key 取得 / SDK インストール / messages.create / model 指定 / system prompt / マルチターン会話 / ストリーミング / エラー処理。

② 問題セット

Q1. Anthropic API key を取得するサイトは?

A. console.anthropic.com。Workbench 兼コンソール。発行後は環境変数 ANTHROPIC_API_KEY で管理。

Q2. Python SDK のインストールコマンドは?

A. pip install anthropic。TypeScript なら npm install @anthropic-ai/sdk。

Q3. messages.create に必須の3パラメータは?

A. model / max_tokens / messages。

Q4. system prompt はどこに渡す?

A. messages.create(system="...", messages=[...]) の system パラメータ。messages 配列の中の "system" ロールでは ない。

Q5. マルチターン会話で会話履歴を保持する方法は?

A. messages 配列に user/assistant メッセージを交互に積む。Claude API はステートレスなのでクライアント側管理。

Q6. レスポンスから本文テキストを取り出すには?

A. response.content[0].text (Python)。content はブロック配列で、type=text のブロックの text を参照。

Q7. ストリーミングを使う API は?

A. client.messages.stream()。with 文 (Python) / for await (TS) で chunk を逐次受信。

Q8. レート制限に達したときのエラーは?

A. HTTP 429 / RateLimitError。retry-after ヘッダで待ち時間がわかる。指数バックオフで再試行が定石。

Q9. モデル ID の例は?

A. claude-opus-4-7 / claude-sonnet-4-6 / claude-haiku-4-5。最新の正式 ID は公式ドキュメント参照。

Q10. stop_reason の主な値は?

A. end_turn (正常終了) / max_tokens (上限到達) / stop_sequence (指定文字列) / tool_use (tool 呼び出し)。
