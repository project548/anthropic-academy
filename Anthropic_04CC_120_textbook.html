Module 5 ・ Lecture 120 ・ Hooks 定義

Defining hooks— Hooks を settings.json に定義する書き方

Anthropic Academy / コース04 Claude Code

① 基本構造

Hooks は ~/.claude/settings.json または {project}/.claude/settings.json の hooks セクションに記載する。

{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "command": "prettier --write \"$FILE_PATH\"",
        "description": "編集後に自動 format"
      }
    ]
  }
}

② 主要フィールド

  • matcher: どの tool で発火するか (正規表現)・例: "Write|Edit", "Bash", ".*"
  • command: 実行するシェルコマンド (環境変数を埋め込み可)
  • description: 何のための hook か (人間用メモ)
  • blocking: 同期実行で結果を Claude に返す (デフォルト false)

③ 利用可能な環境変数

  • $FILE_PATH: 編集対象ファイルのパス
  • $TOOL_INPUT: tool に渡された JSON 入力
  • $TOOL_OUTPUT: tool 実行結果
  • $CLAUDE_PROJECT_DIR: 現在のプロジェクトルート
  • $SESSION_ID: 現セッション ID

④ 実践例 1: 自動 format

{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "command": "node -e \"const f='$FILE_PATH'; if(/\\.(js|ts|tsx|json)$/.test(f)) require('child_process').execSync('npx prettier --write '+f)\"",
        "description": "JS/TS ファイルの自動 format"
      }
    ]
  }
}

⑤ 実践例 2: 危険コマンドブロック

{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "command": "node -e \"let d='';process.stdin.on('data',c=>d+=c);process.stdin.on('end',()=>{const i=JSON.parse(d);if(/rm\\s+-rf\\s+\\//.test(i.tool_input.command)){console.error('BLOCKED: rm -rf /');process.exit(2)}console.log(d)})\"",
        "blocking": true,
        "description": "rm -rf / をブロック"
      }
    ]
  }
}

blocking: true + process.exit(2) で tool 実行を停止できる。

⑥ 実践例 3: セッション終了時の保存

{
  "hooks": {
    "Stop": [
      {
        "command": "powershell -File ~/.claude/scripts/save-session-to-obsidian.ps1",
        "description": "セッション終了時に Obsidian に保存"
      }
    ]
  }
}

⑦ デバッグ・確認方法

  • Hook 実行ログ: ~/.claude/logs/ 配下
  • matcher が効いてるか不安なら matcher: ".*" で全マッチ確認
  • command を echo や log にして無害化テスト
  • blocking 設定で無限ループになっていないか確認

⑧ 中学生向けに例えると

家のセンサー設定。「玄関のドアが開いたら (matcher) → 照明をつける (command)」のようなルール文を JSON で書く。Claude Code の各 tool 実行が「ドアが開く」イベントに相当する。
