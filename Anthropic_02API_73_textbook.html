Defining prompts— MCP server で「プロンプトテンプレ」を提供する

Anthropic Academy / コース02 Claude with the Anthropic API

① Prompt って何?

MCP の3本柱の最後。Prompts は 「サーバー側で用意したプロンプトテンプレート」 をクライアントに提供する仕組み。

例:
  • 「障害レポート作成テンプレ」(変数: 障害名・発生時刻・影響範囲)
  • 「コードレビュー依頼テンプレ」(変数: ファイルパス・レビューポイント)
  • 「議事録要約テンプレ」(変数: 議事録テキスト・出力フォーマット)

② FastMCP での定義

from mcp.server.fastmcp import FastMCP
from mcp.server.fastmcp.prompts import base

mcp = FastMCP("my-server")

@mcp.prompt()
def code_review_request(
    file_path: str,
    focus: str = "general"
) -> list[base.Message]:
    """コードレビュー依頼テンプレ
    Args:
        file_path: レビュー対象ファイル
        focus: 重点ポイント (security/perf/general)
    """
    return [
        base.UserMessage(
            f"以下のファイルをレビューしてください: {file_path}\n"
            f"特に '{focus}' の観点で確認してください。\n"
            "CRITICAL / HIGH / MEDIUM / LOW でラベル付け。"
        )
    ]

③ 3本柱比較

概念提供するもの呼ばれ方
Tools実行アクション (動詞)Claude 自動判断
Resources読み取り専用データ (名詞)ユーザー/アプリが明示
Promptsプロンプトテンプレ (穴埋め)ユーザーが選択 (UIメニュー)

④ ユーザー視点での使い方

Claude Desktop では、ユーザーが 「/」コマンドメニュー から prompt を選択できる。引数を埋めると最終的なプロンプトが生成され、会話に挿入される。

核心: ノーコード的に 「複雑なプロンプトをワンクリック呼び出し」 できる。チーム内で良いプロンプトを共有する仕組み。

⑤ 中学生向けに例えると

「読書感想文の書き方テンプレ」を本棚に置いておく感じ。生徒が選んで穴埋めすれば、整った感想文ができる。プロンプト集の共有版。

⑥ 理解度チェック

Q1. Prompts と Tools の違いは?

Tools = 実行アクション (Claude 自動選択)。Prompts = テンプレ穴埋め (ユーザーが選択 + 引数指定)。
Prompts は会話の入力側に挿入される。Tools は会話中に呼ばれる。
