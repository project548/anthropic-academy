Anthropic Academy / コース04 Claude Code 完結回

① コース04 全体の要約

コース04 では Claude Code を、インストールから自作 hook / SDK 統合まで一通り学んだ。

到達点: 「自然言語で書くプログラミング」を、ターミナル中心の開発フローに自然に組み込めるようになった状態。

② 学んだ要素

  1. セットアップ・初期認証 (#110)
  2. CLAUDE.md による永続的文脈付与 (#111-#112)
  3. diff 承認による安全な編集 (#113)
  4. Context 圧縮と長セッション管理 (#115)
  5. Custom commands で個人最適化 (#116)
  6. MCP server 連携 (#117) と GitHub 統合 (#118)
  7. Hooks による自動化 (#119-#124)
  8. Claude Code SDK でプログラム統合 (#125)

③ 卒業後の最初の一週間

  • Day 1: 自分のプロジェクトで /init → CLAUDE.md 生成
  • Day 2: よく使う指示を slash command 1-2 個に登録
  • Day 3: PostToolUse の自動 format hook 導入
  • Day 4: GitHub MCP 連携 → PR 起票を Claude に任せる
  • Day 5: 危険コマンドブロック hook の導入
  • Day 6-7: 振り返り → 自分の業務固有 hook を1個作る

④ 中長期で目指したいこと

  • 1か月後: 自分の業務独自の slash command 5個・hook 3個
  • 3か月後: 自作 MCP server を公開 / OSS に貢献
  • 半年後: チーム全体のワークフローに Claude Code を組み込み
  • 1年後: Claude Code SDK を使って社内ツール開発
