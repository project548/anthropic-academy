Project setup— MCP サーバ開発のプロジェクト準備

Anthropic Academy / コース03 Model Context Protocol

① ゴール

このコースで作る MCP サーバの開発環境を整える。Python + uv (パッケージマネージャ) + FastMCP を使う最小構成。

到達点: uv run server.py でローカル MCP サーバが起動できる状態。

② 必要なもの

  • Python 3.10+
  • uv (高速パッケージマネージャ・公式推奨)
  • MCP Python SDK (mcp パッケージ)
  • Claude Desktop または MCP Inspector (動作確認用)
  • エディタ (VS Code / Cursor 等)

③ セットアップ手順

# 1. uv のインストール (Mac/Linux)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows (PowerShell)
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

# 2. プロジェクト作成
mkdir my-mcp-server && cd my-mcp-server
uv init

# 3. MCP SDK 追加
uv add "mcp[cli]"

# 4. サーバの雛形作成
touch server.py

# 5. MCP Inspector で起動確認
uv run mcp dev server.py

④ 最小 server.py の例

from mcp.server.fastmcp import FastMCP

mcp = FastMCP("my-first-server")

@mcp.tool()
def hello(name: str) -> str:
    """挨拶を返す"""
    return f"Hello, {name}!"

if __name__ == "__main__":
    mcp.run()

これだけで MCP server が完成。uv run mcp dev server.py で Inspector が立ち上がり、ブラウザで tool を試せる。

⑤ Claude Desktop に登録

// ~/Library/Application Support/Claude/claude_desktop_config.json (Mac)
// %APPDATA%\Claude\claude_desktop_config.json (Windows)
{
  "mcpServers": {
    "my-first-server": {
      "command": "uv",
      "args": ["--directory", "/path/to/my-mcp-server", "run", "server.py"]
    }
  }
}

保存 → Claude Desktop 再起動 → ハンマーアイコンに hello tool が表示される。

⑥ よくあるトラブル

  • uv not found: PATH に追加されているか確認 (~/.local/bin)
  • Server appears but tool missing: server.py の @mcp.tool() デコレータ確認
  • Claude Desktop でログを見たい: ~/Library/Logs/Claude/ (Mac)
  • Inspector が起動しない: Node.js 18+ が必要
