Temperature— 応答のランダム性 (創造性) を調整するパラメータ

Anthropic Academy / コース02 Claude with the Anthropic API

① Temperature とは?

0.0〜1.0 の値で、Claude の応答のランダム性を調整。低い=決定論的 / 高い=創造的。

同じプロンプトでも temperature を変えると応答が変わる。タスクで使い分け。

② 値別の推奨用途

temperature性質適用例
0.0完全に決定論的抽出・分類・数学・factual QA
0.2〜0.5軽くゆらぎ翻訳・要約・コード生成
0.7 (デフォルト)バランス一般対話・チャットbot
1.0創造的・多様創作・ブレスト・小説

③ コード例

response = client.messages.create(
    model="claude-sonnet-4-6",
    max_tokens=1024,
    temperature=0.0,  # 抽出タスクなので決定論的
    messages=[{"role": "user", "content": "次の文から名詞を全部抽出: 桜が満開で公園は人で溢れていた"}]
)
# → "桜, 公園, 人" (毎回同じ)

response = client.messages.create(
    model="claude-sonnet-4-6",
    max_tokens=1024,
    temperature=1.0,  # 創作なので多様性重視
    messages=[{"role": "user", "content": "5行の俳句風ポエムを作って"}]
)
# → 毎回違うポエムが返る

④ 中学生向けに例えると

料理のスパイスのような調節レバー。temperature 0 = 「レシピ通りに作る」/ 1.0 = 「シェフの即興で作る」。同じ材料でも全然違う料理になる。

⑤ 理解度チェック

Q1. temperature 0 と 1 の違いは?

0 = 同じ入力で必ず同じ出力。1 = 毎回違う多様な出力。間の値はその中間。

Q2. どう選ぶ?

抽出・分類など正解がある → 0 / 創作・ブレスト → 1 / 普通の対話 → 0.7。
