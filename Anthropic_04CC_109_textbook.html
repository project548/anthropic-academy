Claude Code in action— Claude Code の実演デモを見る

Anthropic Academy / コース04 Claude Code

① この回で見るもの

講師が実際に Claude Code をターミナルで動かして、典型的な作業を実演する回。文章ではなく 動画 で見ることが本質。ここでは「何が起きているか」の言語化を行う。

目的: 「自然言語で指示する → Claude が複数ファイル自動編集する」というイメージを掴む。細かい仕組みは後の章で学ぶ。

② デモで典型的に見せられること

  1. 起動: ターミナルで claude と打つだけ
  2. 初回プロジェクト把握: Claude が ls / Glob でプロジェクト構造を読む
  3. 自然言語タスク: 「テスト追加して」「バグ直して」
  4. 計画提示: Claude が「これからこういう順序で進めます」と宣言
  5. tool 使用: Read / Edit / Bash が実行される
  6. diff 表示: 変更内容が承認待ち表示
  7. テスト実行: 書いたコードを Claude 自身が npm test で確認

③ 典型的なデモタスク

  • Hello World 生成: 「Express で /hello エンドポイント作って」
  • バグ修正: 「テストが失敗してる、直して」
  • リファクタ: 「この関数を3つに分割して」
  • テスト追加: 「edge case のテストを足して」
  • ドキュメント生成: 「README に API 仕様を書いて」

④ 見るべきポイント

  • Claude が 勝手にやらず計画を提示する
  • ファイル変更前に diff で確認させてくれる
  • Bash 実行は 承認ボタンが出る (危険操作の防衛線)
  • 失敗したら自分で 原因分析 → 再試行する
  • 長い作業でも context を 自動圧縮して継続

⑤ 動画を見た後に試したいこと

# 1. 適当なプロジェクトディレクトリに移動
cd ~/my-project

# 2. Claude Code 起動
claude

# 3. 試す指示
> このプロジェクトの概要を教えて
> 一番複雑な関数を3つ挙げて
> README に「使い方」セクションを追加して

⑥ 中学生向けに例えると

料理ロボの実演動画。「カレー作って」と言ったら、冷蔵庫開けて、玉ねぎ切って、肉炒めて、味見して、皿に盛るまで全部やる。Claude Code もコーディングで同じ。後の章で「どうやって動いてるか」を学ぶ。
