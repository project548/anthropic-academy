③ 演習問題

1 JSONで天気データを取り出す

お題: 「東京の天気をJSONで教えて」と頼んで、Claude には 説明文なしで JSON だけ 返してもらいなさい。

期待する出力例:

{
  "city": "Tokyo",
  "weather": "sunny",
  "temperature": 22
}
💡 ヒント: プレフィルに ```json を埋める。ストップに ``` を指定する。
答えを見る 
messages = []
add_user_message(messages, "Give me a fictional weather report for Tokyo in JSON format")
add_assistant_message(messages, "```json")

text = chat(messages, stop_sequences=["```"])

import json
weather = json.loads(text.strip())
print(weather)

📍 ポイント: ` ```json ` で開き、` ``` ` で閉じる前に停止。json.loads(text.strip()) で Python の辞書に変換。

2 Python関数だけを取り出す

お題: 「2つの数を足す関数を書いて」と頼んで、Claude に コードだけ を返してほしい。普通に頼むと「この関数は…」のような説明文が付いてしまう。

期待する出力:

def add(a, b):
    return a + b
💡 ヒント: JSON の代わりに ```python を使う。
答えを見る 
messages = []
add_user_message(messages, "Write a Python function that adds two numbers")
add_assistant_message(messages, "```python")

code = chat(messages, stop_sequences=["```"])
print(code.strip())

📍 ポイント: 言語が変わっても、コードブロックの種類を変えるだけで同じパターンが効く。

3 箇条書きリストだけを取り出す

お題: 「初心者向けプログラミング言語を5つ挙げて」と頼んで、箇条書きだけを返してほしい。導入文や解説文は不要。

期待する出力:

- Python
- JavaScript
- Ruby
- Scratch
- Go
💡 ヒント: リストは ``` で囲まれないので、別の発想が要る。"- " をプレフィルに、空行(\n\n)をストップにすると…？
答えを見る 
messages = []
add_user_message(messages, "List 5 beginner-friendly programming languages")
add_assistant_message(messages, "- ")

text = chat(messages, stop_sequences=["\n\n"])
print(text.strip())

📍 ポイント: コードブロックではなくリストの「- 」をプレフィルに置くと、Claude は箇条書きモードに入る。空行 \n\n で「箇条書きが終わって解説に移ろうとした瞬間」を捉えて停止。

⑥ 理解度チェック

Q1. JSON 取り出しと Python コード取り出しの違いは？

プレフィルする文字列だけが違う。JSON は ```json、Python は ```python。ストップは両方 ```。同じパターンの中で記号を入れ替えるだけ。

Q2. 箇条書きリストを取り出すとき、ストップシーケンスに何を指定する？

空行 \n\n を指定する。箇条書きが終わって解説文に移る前に、Claude は必ず空行を挟む。そこを捉えて止める。

Q3. 受け取った文字列をすぐ json.loads() に渡せないことがある。なぜ？

前後に余分な改行や空白が入っていることがあるから。text.strip() で削いでから json.loads() に渡す。
