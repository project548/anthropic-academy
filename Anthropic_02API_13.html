① 一言まとめ
このレクチャーではマルチターン会話（Chat exercise）の実装を練習する。Anthropic APIはステートレスで会話履歴を保持しないため、メッセージリストを手動で管理し、毎リクエストに全履歴を含めて送信する仕組みを習得することが目標。
② キーポイント
  • 1
    APIはステートレス — 会話を覚えない
    Anthropic APIは各リクエストを独立して処理する。前のやり取りは自動では引き継がれない。
    ⚠️ 同じAPIを使っても「前回の続き」は自動では成立しない。開発者がコード側で会話履歴を管理する必要がある。
  • 2
    メッセージ構造: role と content のリスト
    会話履歴は role（"user" または "assistant"）と content（テキスト）のペアのリストとして表現する。
    messages = [ {"role": "user", "content": "こんにちは！"}, {"role": "assistant", "content": "こんにちは！何かお手伝いできますか？"}, {"role": "user", "content": "Pythonを教えてください"} ]
  • 3
    毎リクエストに全履歴を送信する
    フォローアップ質問をするときも、会話の全履歴を messages リストに含めてAPIに送る。これによりClaudeは文脈を把握して回答できる。
    ✅ 履歴なしだと「前の話って何？」という文脈ゼロの回答になる。履歴ありなら「さっき話したPythonについてですね」と続けられる。
  • 4
    3つのヘルパー関数で実装をシンプルに
    実装時は以下3つの関数を用意すると管理しやすい：
    def add_user_message(messages, text): messages.append({"role": "user", "content": text}) return messages def add_assistant_message(messages, text): messages.append({"role": "assistant", "content": text}) return messages def chat(messages): response = client.messages.create( model=model, max_tokens=1000, messages=messages ) return response.content[0].text
  • 5
    アシスタントの返答もリストに追加する
    APIからの返答を受け取ったら add_assistant_message でリストに追加し、次のリクエスト時に含める。これを繰り返すことで会話が蓄積される。
③ 会話フロー（ステップ）
1
空のメッセージリストを用意

messages = [] で空リストを初期化する。これがチャット全体の履歴バッファになる。

2
ユーザーのメッセージを追加

add_user_message(messages, "質問内容") でリストに追加。

3
全履歴をAPIに送信して返答を取得

response = chat(messages) でメッセージ全体をAPIに渡して応答を受け取る。

4
アシスタントの返答を履歴に追加

add_assistant_message(messages, response) で返答もリストに追加する。

5
ステップ2〜4を繰り返す

次のユーザー入力でステップ2に戻り、会話を続ける。リストは毎回蓄積されていく。

④ 用語集（初心者向け解説）
マルチターン会話
「こんにちは」→「こんにちは！」→「じゃあ〜は？」のように複数回やり取りが続く会話のこと。
ステートレス
「状態を覚えない」という意味。リクエストのたびに白紙から始まる。前の会話を覚えていない状態。
メッセージ履歴
これまでのやり取り（ユーザーとアシスタント両方）をリスト形式で記録したもの。文脈を伝えるために使う。
role（ロール）
メッセージの送り主を示すキー。"user"（人間）か "assistant"（AI）かを区別する。
content（コンテンツ）
メッセージの本文テキスト。roleとセットで一つのメッセージを構成する。
コンテキスト
「前後の文脈」のこと。過去のやり取りを渡すことで、AIが話の流れを理解できるようになる。
⑤ 理解度チェック
Q1
Anthropic APIが「ステートレス」とはどういう意味ですか？マルチターン会話にどのような影響がありますか？
答えを見る
ステートレスとは、APIが各リクエストを独立して処理し、過去の会話を自動で記憶しないということ。そのため、マルチターン会話を実現するには開発者がコード側でメッセージ履歴リストを管理し、毎リクエストに全履歴を含めて送信する必要がある。
Q2
マルチターン会話に必要な3つのヘルパー関数の名前と役割を答えてください。
答えを見る
① add_user_message(messages, text): ユーザーメッセージを履歴リストに追加する。② add_assistant_message(messages, text): アシスタントの返答を履歴リストに追加する。③ chat(messages): メッセージ履歴全体をAPIに送信してレスポンスを返す。
Q3
APIからの返答を受け取った後、次のリクエストを送る前に必ずやるべきことは何ですか？
答えを見る
add_assistant_message を使ってAPIの返答をメッセージ履歴リストに追加すること。これをしないと、次のリクエスト時にアシスタントの発言が抜けた不完全な履歴が送られてしまい、会話の文脈が途切れる。
