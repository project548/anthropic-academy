ドキュメントの操作— エージェントスキル(Agent Skills) で Word/PDF/Excel を扱う

Anthropic Academy / コース01 Introduction to Agent Skills

① まず結論 — Agent Skills のドキュメント操作って?

Claude の Agent Skills 機能で、Word(.docx) / PowerPoint(.pptx) / Excel(.xlsx) / PDF を作成・編集・読込できる。AnthropicがClaude.ai に組み込み済みのスキルが提供されている。

できること:
  • Word ドキュメントを 新規作成 (見出し・段落・表・画像入り)
  • 既存PowerPoint を 編集 (スライド追加・テキスト書換)
  • Excel で 表データ操作 (関数・グラフ含む)
  • PDF を 読込 + 要約 + 改編

② Agent Skills のしくみ

Skills = 事前定義された手順書のセット。Claude が実行時に必要なskillを動的にロードしてタスク実行する。

# Skills の構成
.claude/skills/
├── docx-creator/
│   ├── SKILL.md       ← 手順書 (Claudeが読む)
│   └── scripts/       ← 実行コード (Python等)
├── xlsx-editor/
└── pdf-processor/
核心: Skills は 「特定領域の専門知識」を切り出してClaude に貸す 仕組み。ドキュメント作成のように「決まった手順がある作業」を高品質に再現できる。

③ どうやって使う?

Claude.ai (Pro/Team/Enterprise) では既にskills が組み込まれている:

  1. Claude.ai で「WordでXX報告書を作って」と頼む
  2. Claude が docx-creator skill を自動ロード
  3. Code Execution sandbox 内でpython-docxを使って .docx 生成
  4. ダウンロード可能な .docx ファイルが応答に添付される
ユーザー視点: 「Wordでマニュアル作って」と話すだけ。Claude が裏側でskillをロード+コード実行+ファイル生成 を全部やる。

④ 自前 skill を作るには

Claude Code では ~/.claude/skills/ に自作 skill を置ける:

# SKILL.md の構造
---
name: my-docx-skill
description: 顧客報告書をWordで作るskill
---

## 使い方
"顧客 {名前} 向けの月次報告書を作って" と頼まれたら...

## 手順
1. テンプレ template.docx を読み込み
2. プレースホルダ置換
3. 保存して返す
Skill = 「ノウハウの再利用パッケージ」。社内で蓄積した独自の作成手順をskill化すれば、誰でも同じ品質で再現できる。

⑤ 中学生向けに例えると

学校の例えSkills の対応
「読書感想文の書き方マニュアル」を本棚から取って読むSkill のロード
マニュアル通りに作文を書くClaude が手順実行
図工で「折り紙の鶴の折り方」を見ながら作るspecialized skill
マニュアル増やせばいろんな作業ができるSkills 追加で機能拡張
核心: Claude は「博識な人」だが「マニュアル(skill)を持つと専門家」になる。文書作業ならskillで Word/PDF プロフェッショナル並み。

⑥ 理解度チェック

Q1. Agent Skills でできるドキュメント操作は?

Word / PowerPoint / Excel / PDF の 作成・編集・読込。Claude.ai に組み込み済みのskillで対応。

Q2. Skill = 何?

手順書(SKILL.md) + 実行コード のセット。Claude が実行時に動的ロードして使う。専門領域のノウハウを切り出して再利用できる。

Q3. Skills のメリットは?

① 高品質再現 (同じ手順で同じ結果) ② 専門知識を切り出して共有可能 ③ Claude のベース能力に追加できる「拡張」として機能
