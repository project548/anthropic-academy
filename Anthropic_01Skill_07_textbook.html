① まず結論 — Claude のコード力

Claude (特に Opus / Sonnet 4.x系) は 業界最高水準のコーディング能力。SWE-bench Verified で74%超達成 (2025年時点)。プログラム作成・デバッグ・リファクタ・テスト生成すべてが可能。

主な使い方:
  • Claude.ai でコードを書いてもらう (ブラウザ)
  • Claude Code でターミナル内開発 (CLI agent)
  • Anthropic API で自前アプリにClaude組込
  • Cursor / VS Code (Copilot Chat) でエディタ統合

② Claude Code — Anthropic 公式 CLI

Claude Code は ターミナル内で動くエージェント型コーディングツール。ファイル読書き・コマンド実行・git操作・テスト・デバッグ等を Claude が自律的に行う。

# インストール
npm install -g @anthropic-ai/claude-code

# 起動
claude

# 例: 自然言語で指示
"src/utils.py の型エラーを直して、テストも書いて"

# Claude が:
# 1. ファイル読み込み (Read)
# 2. エラー特定
# 3. 修正 (Edit)
# 4. test_utils.py 生成 (Write)
# 5. pytest 実行 (Bash)
# 6. 結果確認 + 報告
核心: 「コード書いて」と頼むだけで、Claude が ファイル操作・コマンド実行・検証まで 全部やる。

④ コードで強い領域

  • 新機能実装: 仕様 → コード → テスト
  • デバッグ: エラーメッセージから原因特定 → 修正
  • リファクタリング: 設計改善・命名・分割
  • レガシーコード移行: 古いコードを現代的に書き直す
  • マイグレーション: フレームワーク・言語間の移行
  • テスト生成: カバレッジ拡大
  • ドキュメント自動化: コードから docstring 補完

⑤ ベストプラクティス

1. 計画してから書く

planner エージェントで仕様化 → generator で実装 → evaluator でテスト、の3段階。

2. テスト駆動 (TDD)

tdd-guide skill 使用。先にテスト書く → 失敗確認 → 実装 → 通過 → リファクタ。

3. レビューを必ず

書いた直後に code-reviewer + security-reviewer 起動。CRITICAL/HIGH は必ず修正。

4. 小さく刻む

1関数・1ファイル単位で動かす → 動作確認 → 次へ。大規模一括変更は避ける。

⑦ 理解度チェック

Q1. Claude Code とは?

Anthropic公式のターミナル統合エージェント。ファイル操作・コマンド実行・git操作を Claude が自律的に行う。「コード書いて」「直して」と話すだけで動く。

Q2. コード作業のベストプラクティスは?

① 計画 → 実装 → テストの3段階 ② TDD ③ レビュー必須 ④ 小さく刻む
