① 一言まとめ
Prompt Engineering の 最初の技法。プロンプトの 最初の1行 に「アクション動詞 + 直接的なタスク + 期待する出力仕様」を入れるだけで、平均スコアが 2.32 → 3.92（+1.6 = 4割アップ）。
"Help me with..." "Could you possibly..." といった弱い動詞・前置きを捨て、"Generate / Write / Identify" といった命令形動詞でズバッと始めるのが鉄則。
LLM の位置バイアス（最初のトークンに最も注意を払う）を味方につける、最もコスパの高い技法。

③ 1行構造（3要素）
要素 役割 例
Action verb 「これは命令である」と LLM に伝える起点。タスク完了モードに入れる。 Write / Generate / Identify / Create / Analyze
Direct task 「何を作るか」を一文で明示。修飾を最小化。 "three paragraphs about solar panels" / "a one day meal plan"
Output details 量・形式・スコープを具体化。LLM が早期に出力構造を決定できる。 "three paragraphs" / "with stats" / "in JSON format"
この3要素を最初の1行に詰め込めば「2.32 → 3.92」レベルの改善が出る。すべてのプロンプトに適用できる基本技法。
④ 良い例・悪い例
判定 例 理由
✅ 良い "Write three paragraphs about how solar panels work" 動詞 Write / 量 three paragraphs / トピック明確
✅ 良い "Identify three countries that use geothermal energy and for each include generation stats" 動詞 Identify / 量 three countries / 追加要件明示
✅ 良い "Generate a one day meal plan for an athlete that meets their dietary restrictions" 動詞 Generate / スコープ one day / 制約 dietary restrictions
❌ 悪い "Could you possibly help me with some kind of meal plan?" 弱動詞 help / 量・形式不明 / 余計な丁寧表現
❌ 悪い "I was wondering if you could write something about solar panels." "wondering" は実行コマンドではない / "something" が曖昧
❌ 悪い "Hi Claude! Hope you're doing well. Maybe write something..." 雑談から入る / 選択肢を投げる / LLM が応答モードで返す
悪い例の共通点: ① 弱動詞 ② 量・形式不明 ③ 余計な前置き。これだけで LLM のタスク認識精度が大幅に下がる。

⑥ 理解度チェック
Q1
なぜ「最初の1行」が他の部分より重要なのですか？
答えを見る
LLM は 位置バイアス（最初の数十トークンに最も注意を払う性質）を持つ。最初の1行が曖昧だと、後続の細かい指示が 全体方向性を上書きできない。
逆に最初の1行で正確なタスクを宣言すれば、後続の詳細指示が「補強」として効く。
つまり「最初の1行が成果の50%以上を決める」と言っても過言ではない。
Q2
良いアクション動詞 vs 弱い動詞を3つずつ挙げてください。
答えを見る
✅ 良いアクション動詞: Write / Generate / Identify / Create / Analyze → LLM が「命令」と判別、タスク完了モードに入る。
❌ 弱い動詞: Help me with / Could you possibly / I was wondering → LLM が「応答モード」「質問解釈モード」に入る。雑談・補足説明が増える。
Q3
この技法だけで 2.32 → 3.92 まで改善するが、まだ十分ではない理由は？
答えを見る
Being Clear and Direct は 「タスクを正確に伝える」 技法で、「出力品質をどう上げるか」 までは制御できない。
例えば食事プランで「カロリー計算が雑」「マクロ栄養素が抜ける」「制限違反が残る」等の問題は残る。
これを解決するのが次の技法 Being Specific（具体的なガイドライン・ステップを追加 → 3.92 から 7.86 へ）。
