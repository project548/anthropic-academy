Anthropic Academy / コース04 Claude Code

① このコースは何を学ぶ?

コース04 では Claude Code を扱う。Anthropic 公式のターミナル向け AI エージェントで、ファイル編集・コマンド実行・git 操作までターミナルから自然言語で指示できる。コース02/03 の集大成的な存在。

結論: Claude Code = 「ターミナルに住んでる Claude」。コード書く・読む・実行する・テストする・git する、全部任せられる。

② コース04 の到達点

  • Claude Code をインストール・初期設定できる
  • 自然言語でコード変更・ファイル操作を指示できる
  • MCP server を Claude Code から呼び出せる
  • 独自の slash commands を作成できる
  • CLAUDE.md でプロジェクト固有ルールを学習させられる
  • 大きなコードベースで安全に作業できる

③ なぜ「ターミナル」?

  • IDE 非依存: VS Code でも Cursor でも、生ターミナルでも同じ操作感
  • パイプ可能: git log | claude "コミット要約" のように既存ツールと組合せ
  • 軽量: GUI 不要・SSH 接続先でも動く
  • スクリプタブル: CI/CD やバッチ処理に組込可能
哲学: 開発者は既にターミナルで生きている。新しい UI を覚えさせるより、ターミナルの中に Claude を入れる方が早い。
