Introducing MCP— Model Context Protocol とは何か?

Anthropic Academy / コース03 Model Context Protocol

① MCP とは?

MCP (Model Context Protocol) は、Anthropic が 2024年11月 にオープンソース公開した、LLM と外部の tool / データ源 を繋ぐためのオープン標準。

正式定義: LLM クライアント (Host) と外部リソース (Server) の間の通信プロトコル。JSON-RPC ベース。Anthropic 専用ではなく、誰でも実装できるオープン規格。

② MCP が解決する問題

  • N×M 問題: M個の tool × N個の LLM = N×M 個の実装が必要 → MCP で 1 set に
  • 再利用性ゼロ: 自社で作った tool が他社 LLM では使えない → MCP で共通化
  • tool エコシステム不在: 各社バラバラ → MCP で公開・共有可能
類比: USB-C 規格と同じ。「メーカー独自端子」(API直結) → 「USB-C」(MCP) になり、どの LLM からどの tool も使える。

③ 3層アーキテクチャ

層役割例
Hostユーザー向けアプリ (UI + LLM 呼び出し)Claude Desktop / Claude Code
ClientHost 内部の通信担当 (Server と1対1で接続)MCP Client ライブラリ
Servertool / データを提供する別プロセスGitHub MCP / Lark MCP / 自作サーバ

④ MCP の3つの提供物 (3 Pillars)

  1. Tools (動詞): LLM が呼ぶ関数。副作用あり (DB書込・API呼び出し等)
  2. Resources (名詞): LLM が読むデータ。ファイル・DB行・URL等
  3. Prompts (テンプレ): 再利用可能なプロンプトテンプレート

⑤ MCP の通信例 (概念)

# Claude Desktop (Host) → MCP Server に問い合わせ
{"jsonrpc":"2.0","method":"tools/list","id":1}

# Server 応答
{"jsonrpc":"2.0","id":1,"result":{
  "tools":[
    {"name":"get_weather","description":"...","inputSchema":{...}}
  ]
}}

# Claude が tool 呼び出し決定
{"jsonrpc":"2.0","method":"tools/call","id":2,
 "params":{"name":"get_weather","arguments":{"city":"Tokyo"}}}

# Server 実行 + 結果返却
{"jsonrpc":"2.0","id":2,"result":{"content":[{"type":"text","text":"Tokyo: 20°C"}]}}

⑥ 中学生向けに例えると

家電量販店で「メーカー違うけど、コンセントの形は全部同じ」だから安心して買える。MCP もそれと同じで「LLM 違うけど、tool との繋ぎ方は全部同じ」を実現する。

⑦ 理解度チェック

Q1. MCP の "M" は?

A. Model (Context Protocol)。LLM を中心に据えた標準規格。

Q2. MCP の3層は?

A. Host / Client / Server。Host がUI、Client が通信、Server が tool/データ提供。

Q3. MCP の3 Pillars は?

A. Tools (動詞) / Resources (名詞) / Prompts (テンプレ)。
