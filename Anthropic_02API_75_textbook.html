② 核心まとめ

  • MCP = AI 用 USB-C 規格。1サーバー作れば全AIアプリで使い回せる
  • 3本柱: Tools (動詞) / Resources (名詞) / Prompts (テンプレ)
  • サーバー実装: FastMCP デコレータで関数を即tool/resource/prompt化
  • クライアント実装: ClientSession + stdio_client (or sse_client)
  • デバッグ: mcp dev で Inspector UI
  • 本番連携: Claude Desktop / Cursor / Claude API すべてMCP対応

③ チェックポイント

Q1. MCP の喩えは?

AI 用 USB-C 規格。共通プロトコルで複数AIから複数外部システムへ接続。

Q2. 3本柱は?

Tools (実行) / Resources (参照) / Prompts (テンプレ)

Q3. tool と resource の使い分けは?

副作用あり (実行) → Tool / 副作用なし (読み取り) → Resource。Claude 自動判断 → Tool / ユーザー明示指定 → Resource。

Q4. サーバー開発でデバッグツールは?

MCP Inspector (uv run mcp dev main.py)。ブラウザ UI で tool 実行・JSON-RPC ログ確認。

Q5. 自前 Python クライアント実装の3層は?

StdioServerParameters → stdio_client → ClientSession の3層ネスト。

④ 次に何ができる?

  • 社内システム向け MCP サーバーを書いて、Claude.ai/Code から呼び出し
  • 公開MCP server (GitHub/Slack/Notion) を Claude Desktop に追加して業務効率化
  • 自前アプリに MCP クライアント組込み → Claude+MCP エージェント開発
  • チーム内プロンプト集を prompt 化して全員で共有
