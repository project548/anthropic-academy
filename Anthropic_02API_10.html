① 一言まとめ
このレクチャーではAnthropic APIキーの取得と安全な管理方法を学ぶ。APIキーをハードコーディングせず環境変数として管理する習慣を身につけることで、セキュアなClaudeアプリケーション開発の第一歩を踏み出せる。
② キーポイント
  • 1
    APIキーの取得場所
    Anthropic Console（console.anthropic.com）でアカウント登録後、左メニューの「API Keys」セクションから「Create Key」で発行できる。無料トライアルクレジットも同画面で確認可能。
  • 2
    キーは一度しか表示されない
    発行直後の画面でのみ全文が表示される。画面を閉じると二度と確認できないため、必ずコピーしてパスワードマネージャー等の安全な場所に保存すること。
  • 3
    ハードコードは絶対NG
    ソースコードにキーを直接書くと、GitHubに誤ってプッシュした瞬間に全世界に漏洩する。Anthropicが検知すると自動でキーを無効化するが、その間に不正利用される危険がある。
    ⚠️ api_key="sk-ant-api03-..." のようなハードコードは絶対に避けること
  • 4
    環境変数 ANTHROPIC_API_KEY
    Anthropic Python SDKは起動時に ANTHROPIC_API_KEY という環境変数を自動検索する。この変数にキーを設定しておけば、コード内での明示的な指定が不要になる。
    import anthropic # 引数なし → ANTHROPIC_API_KEY 環境変数を自動読み込み client = anthropic.Anthropic()
  • 5
    .env ファイルで管理する
    プロジェクトルートに .env ファイルを作り ANTHROPIC_API_KEY=sk-ant-... と記述し、python-dotenv ライブラリで読み込む。必ず .gitignore に .env を追加すること。
    ✅ .gitignore に .env を追記 → Git の追跡対象から除外 → キー漏洩リスクゼロ
③ 実装ステップ
1
Anthropic Console でアカウント作成

console.anthropic.com にアクセスしてサインアップ。無料トライアルクレジットが付与される。

2
APIキーを発行する

左メニュー「API Keys」→「Create Key」→ 用途がわかる名前をつけて作成。表示された文字列を必ずコピー（この画面を閉じると二度と見られない）。

3
環境変数に設定する（macOS / Linux）

ターミナルで実行。シェルの設定ファイル（~/.zshrc 等）に追記すると永続化できる。

export ANTHROPIC_API_KEY='sk-ant-api03-xxxxxxxxx'
4
環境変数に設定する（Windows PowerShell）

セッション内のみ有効。永続化はシステムの環境変数設定画面から行う。

$env:ANTHROPIC_API_KEY = 'sk-ant-api03-xxxxxxxxx'
5
.env ファイルを使う方法（推奨）

プロジェクトルートに .env を作成して以下を記述。.gitignore への追記も忘れずに。

# .env ANTHROPIC_API_KEY=sk-ant-api03-xxxxxxxxx
from dotenv import load_dotenv load_dotenv() # .env を読み込む import anthropic client = anthropic.Anthropic() # 環境変数を自動参照
6
動作確認

簡単なメッセージを送って疎通確認する。

message = client.messages.create( model="claude-opus-4-7", max_tokens=64, messages=[{"role": "user", "content": "Hello!"}] ) print(message.content[0].text)
④ 用語集（初心者向け解説）
APIキー
あなただけに発行された「会員証」のような文字列。これを持つ人だけが Claude API を利用できる。他人に見せてはいけない。
環境変数
OS に設定できる「メモ欄」のようなもの。プログラムの外にパスワードを保管でき、コードに直接書かなくて済む。
Anthropic Console
Anthropic が提供する管理画面（console.anthropic.com）。APIキーの発行・使用量の確認・支払い設定などができる。
ハードコード
プログラムのコードの中にパスワードや設定値を直接書き込むこと。APIキーをこうすると GitHub に流出する危険がある。
.env ファイル
環境変数をまとめて書いておくテキストファイル。.gitignore に追加して Git の管理外にすることで安全に使える。
python-dotenv
.env ファイルの内容をプログラムに読み込む Python ライブラリ。pip install python-dotenv でインストールできる。
⑤ 理解度チェック
Q1
APIキーを安全に管理するために最も推奨される方法はどれですか？
答えを見る
環境変数（ANTHROPIC_API_KEY）に設定する方法が推奨される。コードにキーを直接書く「ハードコード」は、Git リポジトリに誤って公開した場合に漏洩するリスクがある。.env ファイル + python-dotenv の組み合わせが実務では一般的。
Q2
client = anthropic.Anthropic() と引数なしで初期化したとき、SDKはどこからAPIキーを取得しますか？
答えを見る
ANTHROPIC_API_KEY という名前の環境変数から自動的に読み込む。事前に環境変数を設定しておけばコード内でキーを明示する必要がなく、ソースコードを公開してもキーが漏れない。
Q3
APIキーが漏洩した可能性に気づいた場合、最初に取るべき行動は何ですか？
答えを見る
すぐに Anthropic Console（console.anthropic.com）にアクセスし、該当キーを削除して新しいキーを発行する。キーが有効な間は第三者に不正利用されて課金される可能性があるため、迷わず即削除が正解。
