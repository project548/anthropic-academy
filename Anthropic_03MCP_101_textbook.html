Defining resources— MCP の Resources (名詞) を定義する

Anthropic Academy / コース03 Model Context Protocol

① Resources とは?

MCP の Resources は 「LLM が読むデータ」。tool が「動詞 (実行)」なら、resource は「名詞 (参照)」。ファイル・DB行・URL の中身など、副作用なしで取得できる情報を提供する。

tool vs resource:
tool = LLM がアクションを起こす (送信・書込・実行)
resource = LLM が読み取って文脈に取り込む (ファイル内容・行データ・ステータス)

② Tool との違い (重要)

観点ToolResource
動詞 / 名詞動詞 (send_email)名詞 (file://...)
副作用あり (書き込み・送信)なし (read only)
呼び出し主体LLM (自律判断)Host (ユーザー指示・LLM 補助)
識別子nameURI (file:// / db:// 等)
主な用途API 呼出・DB 書込文書取込・状態確認

③ FastMCP での定義例

from mcp.server.fastmcp import FastMCP

mcp = FastMCP("docs-server")

@mcp.resource("docs://readme")
def readme() -> str:
    """プロジェクトの README を返す"""
    with open("README.md") as f:
        return f.read()

@mcp.resource("config://app/{key}")
def get_config(key: str) -> str:
    """app設定の指定キーを返す (パラメータ付き)"""
    config = load_config()
    return config.get(key, "")

if __name__ == "__main__":
    mcp.run()

第1引数の文字列が URI テンプレート。{key} のような変数を埋め込める。

④ URI スキーム設計のコツ

  • 名前空間を切る: docs:// / db:// / config:// など用途別に
  • 階層を表す: db://users/{id} のように RESTful に
  • クエリ的なものはパラメータ: logs://errors?limit=100
  • 一覧と詳細を分ける: db://users (一覧) / db://users/{id} (詳細)

⑤ Resource Templates (動的 URI)

@mcp.resource("notes://{date}")
def daily_note(date: str) -> str:
    """指定日のメモを返す。例: notes://2026-05-24"""
    path = f"./notes/{date}.md"
    if not os.path.exists(path):
        raise FileNotFoundError(f"No note for {date}")
    return open(path).read()

URI テンプレートで {date} 部分を可変にすることで、無限のパターンを1つの定義でカバーできる。Client は resources/templates/list でテンプレ一覧を取得する。

⑥ 戻り値の型

  • str: テキスト (Markdown / プレーン)
  • bytes: バイナリ (画像・PDF・音声 等)
  • List[dict]: JSON 配列 (複数行データ)
MIME 設定: @mcp.resource("img://...", mime_type="image/png") でデコレータに明示できる。

⑦ 中学生向けに例えると

tool が「家のスイッチ」(押すと動く) なら、resource は「本棚の本」(読むだけ)。Claude は本棚から本を取り出して、内容を読んで考える。スイッチを押す (副作用) のとは別の役割。

⑧ 理解度チェック

Q1. Resource と Tool の最大の違いは?

A. 副作用の有無。Resource は read-only (読むだけ)・Tool は実行 (送信・書込)。LLM の使い方も変わる。

Q2. Resource の識別子は?

A. URI (Uniform Resource Identifier)。file://, db://, config:// など自由にスキームを設計可能。

Q3. 動的 URI を作るには?

A. @mcp.resource("notes://{date}") のように URI テンプレートを使い、関数引数に変数を受け取る。
