Useful hooks!— 実務で「これ便利」な hook 集

Anthropic Academy / コース04 Claude Code

① 自動 commit checkpoint hook

Claude が編集するたびに自動 git add + commit。あとで気軽にロールバックできる「安全網」。

{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "command": "git -C $CLAUDE_PROJECT_DIR add -A && git -C $CLAUDE_PROJECT_DIR commit -m 'claude: auto checkpoint' --allow-empty 2>/dev/null || true",
        "description": "編集ごとに自動チェックポイント"
      }
    ]
  }
}

② 危険コマンドブロック hook

{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "blocking": true,
        "command": "node -e \"let d='';process.stdin.on('data',c=>d+=c);process.stdin.on('end',()=>{const i=JSON.parse(d);const c=i.tool_input?.command||'';if(/rm\\s+-rf\\s+\\/(\\s|$)|sudo\\s+rm|drop\\s+database|format\\s+c:/i.test(c)){console.error('BLOCKED dangerous command');process.exit(2)}console.log(d)})\"",
        "description": "破壊的コマンドのブロック"
      }
    ]
  }
}

③ 編集後の自動 format hook

{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "command": "node -e \"const fp=process.env.FILE_PATH||'';if(/\\.(ts|tsx|js|jsx|json)$/.test(fp))require('child_process').execSync('npx prettier --write '+fp,{stdio:'ignore'})\"",
        "description": "JS/TS/JSON の自動 format"
      }
    ]
  }
}

④ セッション終了サマリー hook

{
  "hooks": {
    "Stop": [
      {
        "command": "powershell -File ~/.claude/scripts/save-session-to-obsidian.ps1",
        "description": "セッション終了時に Obsidian へ自動保存"
      }
    ]
  }
}

セッションのまとめを Obsidian の daily note に自動投入 → 後で振り返り可能。

⑤ PII redaction hook

{
  "hooks": {
    "UserPromptSubmit": [
      {
        "command": "node ~/.claude/hooks/redact-pii.js",
        "description": "メールアドレス・電話番号を [REDACTED] に置換"
      }
    ]
  }
}

個人情報を含むコードを Claude に渡す前に自動マスク。社内利用での情報漏洩防止。

⑥ 通知 hook (長時間タスク完了)

# Mac
{
  "hooks": {
    "Stop": [
      { "command": "osascript -e 'display notification \"Claude セッション終了\" with title \"Claude Code\"'" }
    ]
  }
}

# Windows (PowerShell)
{
  "hooks": {
    "Stop": [
      { "command": "powershell -c \"[System.Windows.Forms.MessageBox]::Show('Claude セッション終了')\"" }
    ]
  }
}

⑦ Claude が自分でテスト走らせる hook

{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit",
        "command": "cd $CLAUDE_PROJECT_DIR && npm test --silent 2>&1 | head -20",
        "description": "編集後の自動テスト実行"
      }
    ]
  }
}

テスト失敗結果が Claude の context に返る → 自動で「失敗を見て修正」サイクル。

⑧ 中学生向けに例えると

家電の「自動セット」プリセット集。「外出時 = エアコン OFF + 鍵チェック」「帰宅時 = 照明 ON + テレビ ON」のように、よく使うパターンをパッケージ化したもの。Claude Code でも自分の運用ごとに hook をプリセット化できる。
