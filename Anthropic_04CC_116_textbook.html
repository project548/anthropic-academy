Custom commands— 自分専用の slash commands を作る

Anthropic Academy / コース04 Claude Code

① Slash command とは?

Slash command = Claude Code の入力欄で / から始まる短縮コマンド。同じ指示を毎回打たなくて済む。/init, /compact, /clear はビルトイン。自分でも作れる。

核心: 「いつも同じ指示を出している」作業 = slash command 候補。1つ作るだけで毎日の入力が10秒短縮 × 何年も使える。

② 作り方 (1ファイル1コマンド)

# プロジェクト固有
mkdir -p .claude/commands
echo "..." > .claude/commands/review.md

# 全プロジェクト共通 (個人用)
mkdir -p ~/.claude/commands
echo "..." > ~/.claude/commands/morning.md

ファイル名 = コマンド名。review.md → /review として呼べる。

③ 中身は普通のMarkdown

# .claude/commands/review.md
直近の変更をコードレビューしてください。

以下3観点で:
1. バグの可能性
2. テストカバレッジ
3. 可読性 / 命名

最後に severity (critical/high/medium/low) で重要度をつけてください。

このファイル中身が「/review 入力時に自動で投入されるプロンプト」になる。

④ 引数を取れる commands

# .claude/commands/translate.md
次のテキストを日本語に翻訳してください:

$ARGUMENTS

# 使い方
> /translate Hello, how are you?
# → ARGUMENTS = "Hello, how are you?"

$ARGUMENTS プレースホルダーで引数を受け取れる。複雑なものは $1, $2 等も可。

⑤ よくあるカスタムコマンド例

  • /morning: 「今日の予定とタスクを整理してプラン提示」
  • /review: 「直近変更のコードレビュー」
  • /ticket: 「現在の作業を Lark Base にチケット起票」
  • /deploy: 「テスト → ビルド → デプロイの一連実行」
  • /changelog: 「git log から CHANGELOG.md 自動生成」
  • /commit: 「変更を要約してコミットメッセージ生成」

⑥ Slash command vs MCP Prompts

  • Slash command: Claude Code 専用 / ローカル md / 個人 or プロジェクト
  • MCP Prompt: 標準プロトコル / 別プロセス / 全 MCP クライアント共通

個人用は slash command が手軽。組織で共有なら MCP Prompt 化。

⑦ 中学生向けに例えると

電卓の「メモリーボタン」みたいなもの。よく使う計算式を1ボタンに登録しておくと、毎回手入力しなくていい。slash command も同じで、よく使う Claude への指示を1つの単語にまとめておける。
