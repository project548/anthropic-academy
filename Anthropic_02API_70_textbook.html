① 本章の目的

#66 でクライアントの概念、#67-#69 でサーバー側を学んだ。今度は Python で MCP クライアントを自分で書く 番。Claude Desktop / Cursor を使わず、自前アプリから MCP サーバーに繋ぐ実装。

ゴール: 自前 Python アプリから MCP サーバーに繋いで tools/list + tools/call ができるようになる。

② 最小クライアント実装 (stdio)

from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client
import asyncio

async def main():
    # サーバー起動パラメータ
    server_params = StdioServerParameters(
        command="python",
        args=["weather_server.py"],  # 起動する MCP server
    )

    # stdio で接続
    async with stdio_client(server_params) as (read, write):
        async with ClientSession(read, write) as session:
            # 1. 初期化 (capability negotiation)
            await session.initialize()

            # 2. tool 一覧取得
            tools = await session.list_tools()
            for t in tools.tools:
                print(f"- {t.name}: {t.description}")

            # 3. tool 呼び出し
            result = await session.call_tool(
                "get_weather",
                arguments={"city": "Tokyo"}
            )
            print(result.content[0].text)

asyncio.run(main())

③ 流れ — 5ステップ

  1. StdioServerParameters: サーバー起動コマンドを定義
  2. stdio_client: 子プロセスを起動 + stdio パイプを開く
  3. ClientSession: 接続セッション確立
  4. session.initialize(): capability negotiation
  5. list_tools / call_tool / read_resource / get_prompt: API 呼び出し

④ Claude API と組み合わせる

# MCP server の tools を取得 → Claude API に渡す
tools_list = await session.list_tools()
anthropic_tools = [
    {"name": t.name, "description": t.description, "input_schema": t.inputSchema}
    for t in tools_list.tools
]

response = client.messages.create(
    model="claude-opus-4-7",
    max_tokens=1024,
    tools=anthropic_tools,
    messages=[{"role": "user", "content": "東京の天気は?"}]
)

# Claude が tool_use を要求したら MCP server に転送

⑦ 理解度チェック

Q1. クライアント実装の3層は?

StdioServerParameters → stdio_client → ClientSession の3層をネストしてセッション確立。

Q2. Claude API と組合せるには?

① MCP server から tools 一覧取得 ② Claude API に tools として渡す ③ Claude が tool_use 要求 ④ MCP server に call_tool で転送 ⑤ 結果を Claude に戻す。
