The Claude Code SDK— Claude Code をプログラムから呼び出す SDK

Anthropic Academy / コース04 Claude Code

① Claude Code SDK とは?

Claude Code SDK = ターミナル CLI としての Claude Code を、自分のアプリ・スクリプトの中から呼び出すための公式ライブラリ。Python / TypeScript 両対応 (Claude Agent SDK としても展開)。

核心: 「Claude Code が持っているエージェント能力を、自分のプロダクトに組み込める」。CLI を超えてサーバサイド・CI/CD・カスタムアプリで使える。

② CLI vs SDK

  • CLI: 開発者が手で claude と打って対話
  • SDK: コードから呼び出してプログラマブルに動かす

同じ Claude Code エンジンを、入口だけ変えて使う。

③ TypeScript SDK の例

import { query } from "@anthropic-ai/claude-agent-sdk";

const result = query({
  prompt: "package.json の依存を最新版に更新するパッチを生成",
  options: {
    cwd: "/path/to/my-project",
    permissionMode: "acceptEdits",
    allowedTools: ["Read", "Edit", "Bash"],
  }
});

for await (const message of result) {
  if (message.type === "result") {
    console.log(message.result);
  }
}

④ Python SDK の例

from claude_agent_sdk import query, ClaudeAgentOptions

options = ClaudeAgentOptions(
    cwd="/path/to/my-project",
    permission_mode="acceptEdits",
    allowed_tools=["Read", "Edit", "Bash"],
)

async for message in query(
    prompt="テスト追加して全部通るまで修正して",
    options=options
):
    if message.type == "result":
        print(message.result)

⑤ ユースケース

  • CI/CD 統合: PR ごとに Claude が自動レビュー
  • カスタムアプリ: 社内ツールに「Claude エージェント」機能を埋め込む
  • バッチ処理: 100ファイルに同じ refactor を並列適用
  • カスタム CLI: 自社専用の mycli ai コマンドの裏で Claude Code を呼ぶ
  • サブエージェント: メイン Claude Code から別の Claude エージェントを起動

⑥ オプションの重要パラメータ

  • cwd: 作業ディレクトリ
  • model: 使用モデル (opus / sonnet / haiku)
  • permissionMode: default / acceptEdits / bypassPermissions / plan
  • allowedTools: 使える tool の whitelist
  • disallowedTools: 禁止 tool
  • maxTurns: 最大対話ターン数 (無限ループ防止)

⑦ セキュリティ

  • bypassPermissions は 本番運用厳禁。検証用のみ
  • 本番では allowedTools で必要最小限に絞る
  • cwd を信頼できないパスに設定しない (任意のディレクトリ操作許可になる)
  • API key / token はコード埋め込み禁止。環境変数で

⑧ 中学生向けに例えると

料理ロボットの「メーカー直営アプリ」のSDK版。普通は手で操作 (CLI) するけど、SDKを使うと「自社の業務アプリ」の中にロボの機能を組み込める。スマートホーム家電を社内ツールから呼ぶイメージ。
