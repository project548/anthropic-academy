Parallelization workflows— 独立タスクを並列で動かす workflow パターン

Anthropic Academy / コース02 Claude with the Anthropic API

① パターン定義

Parallelization = 互いに依存しない複数のLLM呼び出しを 同時並行 で実行 → 結果を集約する workflow パターン。

2つのサブパターン:
  • Sectioning: 1つのタスクを並列に分割 (例: 文章の章ごとに別Claudeに要約させて結合)
  • Voting: 同じタスクを複数回並列実行 → 多数決で結論 (品質UP)

② コード例 (asyncio.gather)

import asyncio
from anthropic import AsyncAnthropic

client = AsyncAnthropic()

async def review_aspect(code: str, aspect: str) -> str:
    """1観点で並列レビュー"""
    response = await client.messages.create(
        model="claude-sonnet-4-6",
        max_tokens=1024,
        messages=[{"role": "user", "content":
            f"以下のコードを {aspect} 観点でレビューして:\n{code}"
        }]
    )
    return f"[{aspect}] {response.content[0].text}"

async def parallel_review(code: str):
    aspects = ["security", "performance", "readability", "testability"]
    # 4観点を並列実行
    results = await asyncio.gather(
        *[review_aspect(code, a) for a in aspects]
    )
    return "\n\n".join(results)

# 直列なら 4回 × 2秒 = 8秒
# 並列なら max(2秒) × 4 = 約2秒

③ 使い所

  • 独立評価の集約: 多観点コードレビュー / 多軸分析
  • 多数決: 同じ質問を3回投げて多数決 (品質保証)
  • 大量データ処理: 100ファイルを並列要約
  • 監視・ガードレール: 本処理と「これは安全か?」チェックを並列で

④ 注意点

  • Rate limit に注意 (一気に呼ぶと制限に当たる)
  • 並列度は 5〜10 程度推奨。100並列はNG
  • 各サブタスクは 本当に独立 か確認 (依存があれば chaining)
並列ツール: Python なら asyncio.gather / Node.js なら Promise.all / Anthropic Batch API も並列実行に有効。

⑤ 中学生向けに例えると

料理で「野菜切り」「肉炒め」「味噌汁」を1人で順番にやると30分。3人で並列にやると10分。独立した作業なら人数増やせば速い。
