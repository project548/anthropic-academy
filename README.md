# anthropic-academy

Claude Partner Network Learning Path - HTML lecture materials

## 2種類の HTML

各レクチャーには **2タイプ** の HTML が用意されている。

| タイプ | サフィックス | 対象 | 特徴 |
|---|---|---|---|
| **学習版** | `_NUM.html` | 学習進行中の自分用 | 簡潔な要点まとめ・進行管理 |
| **教科書版** | `_NUM_textbook.html` | 中学生でも読める教科書 | SVG イラスト・身近な例え話・理解度チェック Q&A |

GitHub Pages 公開: https://project548.github.io/anthropic-academy/

## 教科書版の特徴 (#18-#28 確立)

- 韓国語教科書スタイルの参考デザイン (角丸ベージュ帯 / 単語表 薄茶背景 / たっぷり余白)
- インライン SVG イラスト 2-5枚 (比喩図・対比図・流れ図)
- 単語表で英語キーワードを 「英語 / 読み方 / 意味」 の3列構成
- 食卓・模試・学校・紙の例え話で身近に
- 理解度チェック Q&A は `<details>` で答え隠し (自分で考えてから開く)
- 演習回はオリジナル統合演習問題3問を用意
