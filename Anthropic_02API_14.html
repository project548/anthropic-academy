① 一言まとめ
システムプロンプトは、Claudeの応答スタイルとトーンをロール（役割）の割り当てによりカスタマイズする技術。「何を答えるか」ではなく「どう答えるか」を制御することで、同じ質問でも目的に応じた全く異なる応答スタイルを実現できる。
② キーポイント
  • 1
    システムプロンプトの目的：「どう答えるか」の制御
    システムプロンプトはClaudeの応答「内容」ではなく「スタイルと姿勢」を制御する。同じ質問でも、割り当てるロールによって応答の方向性が変わる。
    💡 例：「2 + 2 = ?」に対して
    ・ロールなし → 「4です」
    ・数学チューター → 「一緒に考えてみましょう。2つのリンゴと2つのリンゴを合わせると…？」
  • 2
    実装方法：system キーワード引数に文字列を渡す
    client.messages.create() の system パラメータにプレーンな文字列として渡す。
    response = client.messages.create( model="claude-opus-4-5", max_tokens=1024, system="You are a patient math tutor. Give hints, not answers.", messages=[{"role": "user", "content": "What is 2 + 2?"}] )
  • 3
    構造：最初の行でロール宣言 → 具体的な行動指示
    システムプロンプトの典型的な構造は「役割の宣言」を最初に置き、続けて具体的な振る舞いの指示を記述する。
    You are a patient math tutor. Help students learn by giving hints rather than direct answers. Ask guiding questions to encourage student thinking. Never simply provide the answer without explanation.
  • 4
    Noneケースの実装：システムプロンプトが不要な場合は除外する
    システムプロンプトが None の場合は system パラメータ自体を渡さない。paramsディクショナリを使った ** アンパックが便利。
    def chat(messages, system=None): params = { "model": "claude-opus-4-5", "max_tokens": 1024, "messages": messages, } if system: params["system"] = system return client.messages.create(**params)
    ⚠️ system=None をそのままAPIに渡すとエラーになることがある。条件分岐で除外するのがベストプラクティス。
  • 5
    ユースケース例：数学チューター
    「あなたは忍耐強い数学チューターです」というロールを与えると、Claudeは直接答えを出さず、ヒントや誘導質問で学習者の思考を促すようになる。このように、同一のロジックで異なるペルソナを使い分けられるのがシステムプロンプトの強力な点。
    ✅ システムプロンプトはマルチターン会話（チャット）全体に継続的に適用される。最初に一度設定すれば会話中ずっと有効。

④ 用語集（初心者向け解説）
システムプロンプト
Claudeの「役割」や「振る舞い方」を事前に設定するための特別な指示文。会話全体の姿勢を決める。
ロール（役割）
「あなたは○○です」とClaudeに担わせる役割。数学チューター・カスタマーサポート担当など。
system パラメータ
client.messages.create() に渡す引数のひとつ。文字列でシステムプロンプトを指定する。
** アンパック（展開）
Pythonの辞書（dict）をキーワード引数として関数に渡す記法。func(**{"a": 1}) は func(a=1) と同じ。
paramsディクショナリ
APIリクエストに渡す引数を辞書形式でまとめたもの。条件に応じてキーを追加してからアンパックで渡せる。
マルチターン会話
複数の発言を往復する会話。システムプロンプトはこの会話全体に渡って有効になる。
⑤ 理解度チェック
Q1
システムプロンプトで制御するのは「何を答えるか」と「どう答えるか」のどちらですか？
答えを見る
「どう答えるか」。システムプロンプトはClaudeの応答スタイル・トーン・姿勢を制御するもので、情報の内容自体ではなく応答のアプローチを変える。
Q2
システムプロンプトが提供されない（None）場合、どのように実装すればよいですか？
答えを見る
paramsディクショナリを使って条件分岐し、system が None でなければだけ辞書に追加する。その後 **params でアンパックして create() に渡すことで、system パラメータ自体を渡さないようにできる。
Q3
数学チューターのシステムプロンプトを設定すると、Claudeの応答はどう変わりますか？
答えを見る
直接的な答えを出さず、ヒントや誘導質問を通じて学習者自身が考えて解答にたどり着けるよう促す。同じ「2+2は？」という質問でも、答え「4」を言う代わりに考え方を一緒に探る応答になる。
