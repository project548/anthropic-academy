① 一言まとめ
このレクチャーではツール使用時のストリーミングと、JSONバリデーションを無効化して即時チャンクを受け取るFine-Grainedツール呼び出しを学ぶ。デフォルトモードとFine-Grainedモードのトレードオフを理解することで、レスポンシブなUIとデータ整合性のバランスを適切に取れるようになる。
② キーポイント
  • 1
    ツールストリーミングの追加イベント
    通常のストリーミングに加え、ツール使用時は input_json_delta イベントが追加される。各イベントは partial_json（そのチャンクの断片）と snapshot（受信済み累積）の2フィールドを持つ。
    // ストリーミングイベント例 { type: "input_json_delta", partial_json: '"city": "Tokyo"', snapshot: '{"city": "Tokyo"' }
  • 2
    デフォルト動作の遅延原因
    デフォルトでは、APIがJSONの完全なキーバリューペアが揃うまでバッファリングし、スキーマに対してバリデーションを行ってから送信する。そのため処理が遅延し、検証完了後にまとめてバースト状に届く。
  • 3
    Fine-Grainedモードの有効化
    fine_grained: true を設定するとAPIサイドのJSONバリデーションが無効化され、生成直後のチャンクが即送信される。
    client.messages.stream({ model: "claude-opus-4-5", tools: [...], fine_grained: true, // ← バリデーション無効化 messages: [...] })
    ✅ 従来のストリーミング体験と同等のリアルタイム応答が実現できる
  • 4
    Fine-Grainedのリスクと対処
    バリデーション省略により、null の代わりに "undefined" など不正なJSONが届く可能性がある。クライアント側で必ずエラーハンドリングを実装すること。
    ⚠️ デフォルトモードでは不正なJSONが文字列としてラップされる場合がある。Fine-Grainedでは生チャンクが来るためtry-catchが必須。
  • 5
    用途に応じたモード選択指針
    UIの即時更新やツール引数の早期処理が必要な場合はFine-Grainedを選ぶ。バリデーション遅延が許容できる場合はデフォルトで十分。まずデフォルトで始め、UX改善が必要なときだけFine-Grainedを検討する。

④ 用語集（初心者向け解説）
content_block_delta
ストリーミング中にテキストのかけら（チャンク）を伝えるイベント。通常のテキスト応答で使われる。
input_json_delta
ツール呼び出しのJSON引数のかけらを伝えるストリーミングイベント。ツール使用時に追加される。
partial_json
そのチャンクで届いたJSONの断片。単体では不完全なJSONであることが多い。
snapshot
その時点までに受信したJSONの累積文字列。これを使うと途中経過を追いやすい。
Fine-Grained
「細粒度」の意味。ツール呼び出し時にJSONバリデーションをスキップして即座にチャンクを送る設定。
バリデーション
データが正しい形式・構造かどうかをチェックすること。不正なデータを弾くための検証処理。
バースト
遅延の後にまとめてデータが一気に届く現象。デフォルトのツールストリーミングで見られる。
ストリーミング
完成を待たず、生成しながらリアルタイムで結果を少しずつ送り続ける技術。
⑤ 理解度チェック
Q1
Fine-Grainedモードを有効にするには、APIリクエストに何を追加しますか？
答えを見る
fine_grained: true を追加する。これによりAPIサイドのJSONバリデーションが無効になり、生成直後のチャンクが即座に送信される。
Q2
デフォルトのツールストリーミングで遅延（バースト）が発生する理由を説明してください。
答えを見る
APIがJSONの完全なキーバリューペアが揃うまでバッファリングし、スキーマに対してバリデーションを行ってからチャンクを送信するため。検証が終わるとまとめてバーストで届く。
Q3
Fine-Grainedモードを使う場合、クライアント側でどのような対応が必要ですか？その理由も答えてください。
答えを見る
try-catchでJSONパースエラーをキャッチするエラーハンドリングを実装する必要がある。理由はAPIバリデーションが省略されるため、nullの代わりに"undefined"等の不正なJSONが届く可能性があるから。
