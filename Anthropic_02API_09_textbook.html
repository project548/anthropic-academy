APIへのアクセス— Claude API を呼ぶ前の準備と方法

Anthropic Academy / コース02 Claude with the Anthropic API

① Claude API へのアクセス手段

Claude API は3つの経路でアクセス可能:

  • ① Anthropic API 直接: api.anthropic.com (本コース)
  • ② AWS Bedrock: AWS統合 (エンタープライズ)
  • ③ Google Vertex AI: GCP統合
本コースで使うのは ①。クレジットカード or 無料クレジット (新規登録時) で開始できる。

② 必要な準備 3点

  1. Anthropic アカウント: console.anthropic.com で作成 (無料)
  2. 支払い設定: クレジットカード追加 + Pay-as-you-go へ移行
  3. APIキー発行: Console から API Keys タブ (#10 で詳述)
料金: 新規登録時 $5 無料クレジット付与。これでチュートリアル + #10-#28 の演習を十分こなせる。

③ Pay-as-you-go (従量課金) の流れ

# 課金は呼んだ分だけ
# 例: claude-sonnet-4-6 で 1リクエスト = 1000 input + 500 output tokens
# Input: 1000 × $3 / 1M = $0.003
# Output: 500 × $15 / 1M = $0.0075
# 合計: 約 $0.01 / 呼び出し

# 1日100リクエストでも 約 $1/日
# 個人開発なら月数千円程度
使った分だけ課金。試すだけなら無料クレジットで完結。

④ Rate Limits (利用制限)

アカウントのUsage Tier でリクエスト数・トークン量に上限がある:

  • Tier 1: 新規アカウント (50リクエスト/分)
  • Tier 2-4: $400+消費 + 経過日数 で自動昇格
  • 大規模利用はEnterprise契約でカスタム上限
最初は Tier 1 で十分。本番アプリ運用が見えたら段階的に昇格。

⑤ SDK の用意 (推奨)

# Python
pip install anthropic

# TypeScript
npm install @anthropic-ai/sdk

# 他: Go, Java, Ruby, PHP も公式SDK提供
SDK使うメリット: 型安全 + 自動retry + streaming対応 + tool/file等の高レベルAPI。生cURLでもOKだが、本コースは Python SDK で進める。

⑥ 中学生向けに例えると

「自動販売機(Claude)を使うのにコイン(APIキー)が必要」「使った分だけ料金(トークン課金)」「1回に取れる本数に上限(rate limit)」。コインを買えば(クレカ登録)即使える。

⑦ 理解度チェック

Q1. Claude API へのアクセス経路は?

① Anthropic API直接 ② AWS Bedrock ③ GCP Vertex AI の3つ。本コースは①。

Q2. 料金体系は?

Pay-as-you-go (従量課金)。input/outputトークン量で計算。新規登録時の $5無料クレジットでチュートリアル完走可能。
