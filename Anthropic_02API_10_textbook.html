APIキーの取得— Console で発行 + 環境変数で安全に管理

Anthropic Academy / コース02 Claude with the Anthropic API

① APIキーって何?

Claude API を呼ぶときの認証トークン。あなたのアカウントを識別 + 課金紐付け + アクセス制御 を全部担う。絶対に他人に見せない。

セキュリティ: APIキー漏洩 = 他人が課金できる。Git に commit しない・公開リポジトリに置かない・チャットに貼らない。

② 発行手順

  1. console.anthropic.com ログイン
  2. 左メニュー「API Keys」
  3. 「Create Key」クリック
  4. 用途名 (例: "study-key") + 環境 (Dev/Prod) を選ぶ
  5. 表示された sk-ant-api03-... を 即コピー保管 (再表示不可)
作成直後の1回しか表示されない。誤ってブラウザ閉じたら再発行。

③ 環境変数に保存する (推奨)

# macOS / Linux (.zshrc or .bashrc)
export ANTHROPIC_API_KEY="sk-ant-api03-xxx..."

# Windows PowerShell
$env:ANTHROPIC_API_KEY = "sk-ant-api03-xxx..."

# .env ファイル (プロジェクト内・gitignoreに追加)
ANTHROPIC_API_KEY=sk-ant-api03-xxx...
Python SDK は自動的に ANTHROPIC_API_KEY 環境変数を読む。コード内に直書きは絶対NG。

④ Python での読み込み

# dotenv で .env を読む方式 (推奨)
from dotenv import load_dotenv
from anthropic import Anthropic

load_dotenv()  # .env の中身を環境変数にロード
client = Anthropic()  # ANTHROPIC_API_KEY を自動取得

# 明示渡しも可能 (非推奨)
client = Anthropic(api_key="sk-ant-api03-xxx...")  # ← NGパターン

⑤ キー漏洩時の対応

  1. Console > API Keys で該当キーを即削除 (Revoke)
  2. 新しいキーを発行 → 環境変数更新
  3. 過去24時間の使用量を確認 → 不正利用ないか確認
  4. 不正利用あればAnthropicサポートに連絡
GitHub push してしまった場合: commit削除では不十分 (履歴に残る)。必ず Console でキーを Revoke + 新発行。

⑥ 中学生向けに例えると

「自宅の鍵 = APIキー」。失くしたら鍵交換 (Revoke)、絶対に他人に貸さない、メモを家の前に置かない (gitに上げない)。

⑦ 理解度チェック

Q1. APIキーをコード内に直書きしてはいけない理由は?

Git commit + GitHub push で世界中に晒される。他人があなたの課金で API を呼び放題。漏洩時は即 Revoke + 新発行。

Q2. 正しい保管方法は?

環境変数 (.env + .gitignore) で管理 → SDK が自動取得。本番環境では Secret Manager (AWS/GCP) を使う。
