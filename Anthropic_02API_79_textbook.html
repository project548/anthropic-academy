Claude Code setup— Anthropic 公式CLI のインストールと初期設定

Anthropic Academy / コース02 Claude with the Anthropic API

① Claude Code とは?

ターミナルで動くエージェント型コーディングツール。ファイル読書き・コマンド実行・git・テスト等を Claude が自律的にこなす。Cursor等とは違い、エディタ非依存・ターミナル統合型。

強み: 既存の開発フローに「claude」コマンド1つで追加できる。エディタを変えなくて良い。

② インストール (3コマンド)

# 1. インストール (npm 経由)
npm install -g @anthropic-ai/claude-code

# 2. ログイン (API key or Claude.ai アカウント)
claude

# 3. 確認
claude --version
推奨: Node.js 20+ / npm 10+ / Git。Python 必須ではないが多くのプロジェクトで併用。

③ 初期化 (プロジェクトごと)

# プロジェクトディレクトリで
cd my-project
claude

# Claude が自動的に:
# - CLAUDE.md があれば読み込む (プロジェクト固有指示)
# - .claude/ 配下のスキル/エージェント定義をロード
# - git 状態を把握
# - "ようこそ" + 提案

④ 主要コマンド

  • /help — ヘルプ
  • /init — プロジェクト初期化 (CLAUDE.md 生成)
  • /clear — 会話履歴クリア
  • claude mcp add — MCP サーバー追加
  • ! プレフィックス — シェルコマンドを直接実行 (例: !ls)
  • @ プレフィックス — ファイル参照 (例: @src/utils.py)

⑤ CLAUDE.md の役割

# プロジェクトルートに CLAUDE.md を置くと
# Claude が起動時に毎回読み込む

# 例:
- プロジェクトのコーディング規約
- 既存アーキテクチャの説明
- 「○○はやらないで」というルール
- 主要なスクリプト・ディレクトリ
CLAUDE.md = Claude への「永続指示」。書いておけば毎回伝え直さなくて済む。

⑥ 中学生向けに例えると

有能な助手 (Claude Code) を雇って、机の上 (プロジェクト) で一緒に作業する。机のルール (CLAUDE.md) を渡しておけば、毎回ルール説明しなくて良い。
