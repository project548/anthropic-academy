① なぜ Claude にデータセットを作らせる?

図① 手書き vs Claude 自動生成

今回作るのは「AWS コード支援プロンプト」の評価データセット。説明文なしで Python / JSON config / Regex のいずれかだけを出力するプロンプトを評価したい。

② 実装の4ステップ

図② 4ステップの流れ

1chat() ヘルパー関数を改良

system / temperature / stop_sequences を渡せるように拡張する。

def chat(messages, system=None, temperature=1.0, stop_sequences=None):
    params = {
        "model": model,
        "max_tokens": 1000,
        "messages": messages,
        "temperature": temperature
    }
    if system:
        params["system"] = system
    if stop_sequences:
        params["stop_sequences"] = stop_sequences

    response = client.messages.create(**params)
    return response.content[0].text

こうしておくと、データセット生成時に temperature を上げて多様性を増やせる。

2generate_dataset() 関数を書く

Claude に「テストケースを N 個作って」と頼む。プレフィル+ストップ で raw JSON を取得。

def generate_dataset():
    prompt = """
Generate an evaluation dataset...
* Focus on Python/JSON/Regex tasks
* Please generate 3 objects.
"""
    messages = []
    add_user_message(messages, prompt)
    add_assistant_message(messages, "```json")
    text = chat(messages, stop_sequences=["```"])
    return json.loads(text)

3動かして結果を確認

dataset = generate_dataset()
print(dataset)

3つのテストケース(Python関数 / JSON config / Regex)が JSON で返ってくる。

4ファイルに保存

with open('dataset.json', 'w') as f:
    json.dump(dataset, f, indent=2)

dataset.json ファイルができる。次の評価ステップで何度も使い回せる。

⑥ 理解度チェック

Q1. なぜ Claude にデータセットを作らせる?

手で書くと時間がかかる・発想が偏る・大量に作るのが苦痛。Claude なら数秒で数十・数百ケース、多様な切り口で生成できる。Haiku 等の速いモデルなら安い。

Q2. なぜ chat() に temperature を渡せるようにする?

データセット生成時に temperature を上げると Claude の出力にバラツキが出る → より多様なテストケースが集まる。本番評価時は低めの temperature でブレを抑える。

Q3. なぜ dataset.json にファイル保存する?

再現性と使い回しのため。同じデータセットで何度も評価すれば、プロンプトの違いだけがスコアに反映される。別のプロンプトを評価する時も同じデータを使える。

Q4. 「もっと例が欲しい」となったら?

プロンプト内の生成数を 3 から 30 や 300 に変えて再実行。コードはほぼ変えなくていい。
