② 問題セット (理解度チェック)

Q1. MCP の正式名称は?

A. Model Context Protocol。LLM と外部 tool / データ源を繋ぐためのオープン標準 (2024-11 Anthropic 公開)。

Q2. MCP の3層アーキテクチャは?

A. Host / Client / Server。Host = UI アプリ (Claude Desktop 等) / Client = 通信担当 (Host 内部・1対1で Server と接続) / Server = tool/データ提供 (別プロセス)。

Q3. MCP の3 Pillars は?

A. Tools (動詞) / Resources (名詞) / Prompts (テンプレ)。それぞれ役割が異なる。

Q4. Tool と Resource の最大の違いは?

A. 副作用の有無。Tool は実行 (副作用あり・LLM が呼ぶ) / Resource は読取 (副作用なし・Host/ユーザーが呼ぶ)。

Q5. FastMCP で tool を定義する方法は?

A. @mcp.tool() デコレータ + 関数。型ヒント + docstring で input schema が自動生成される。

Q6. Resource の識別子は何を使う?

A. URI。file://, db://, config:// など自由にスキーム設計可能。動的 URI は @mcp.resource("notes://{date}") のようにテンプレ化。

Q7. Prompt は誰が呼ぶ?

A. ユーザー。Claude Desktop で / を入力 → 一覧から選択 → 引数入力 → LLM へ送信。

Q8. MCP Inspector の役割は?

A. Claude Desktop に登録する前の動作確認用 GUI。uv run mcp dev server.py で起動。tool/resource/prompt を一覧表示・手動実行・ログ確認可能。

Q9. MCP の通信プロトコルは?

A. JSON-RPC 2.0。stdio (ローカル) or HTTP (SSE) で通信。tools/list, tools/call, resources/list, resources/read, prompts/list 等のメソッド。

Q10. Claude Desktop に MCP server を登録する設定ファイルは?

A. claude_desktop_config.json。mcpServers キーに command と args を記載。Mac: ~/Library/Application Support/Claude/ / Windows: %APPDATA%\Claude\。
