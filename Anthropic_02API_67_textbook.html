Project setup— MCP サーバーを自作する前の環境構築 (Python uv + MCP SDK)

Anthropic Academy / コース02 Claude with the Anthropic API

① 本章の目的

#66 でクライアント側を理解した。今度は 自分でMCPサーバーを書く 番。本章は 実装に入る前のプロジェクトセットアップ を体系化する。

セットアップで揃えるもの:
  1. Python 3.10+ (推奨は 3.11)
  2. uv (Anthropic公式推奨のPythonパッケージマネージャ)
  3. mcp[cli] パッケージ (公式SDK + CLI)
  4. プロジェクトディレクトリ + main.py の雛形

② なぜ uv なのか?

観点pip / venv (従来)uv (推奨)
速度遅い10〜100倍速い (Rust製)
セットアップvenv 作成 + activate + pip installuv init で1発
依存解決requirements.txt 手動pyproject.toml 自動
Python本体事前インストール必要uv が自動取得
Anthropic推奨—公式採用

③ uv のインストール

# macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows (PowerShell)
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

# 確認
uv --version
インストール後: シェルを再起動すると uv コマンドが使えるようになる。

④ プロジェクト初期化 (4ステップ)

# 1. プロジェクトフォルダ作成
mkdir weather-mcp
cd weather-mcp

# 2. uv プロジェクト初期化 (Python 3.11)
uv init --python 3.11
# → pyproject.toml, .python-version, README.md, main.py 等が生成

# 3. MCP SDK インストール
uv add "mcp[cli]" httpx
# pyproject.toml に依存追加 + uv.lock に固定 + .venv 作成

# 4. main.py を MCP サーバー雛形に書き換え
uv add の威力: 数秒で依存解決完了。[cli] extras を付けることで mcp dev 等のCLIコマンドも入る。

⑤ MCP サーバーの最小雛形 (main.py)

from mcp.server.fastmcp import FastMCP

# サーバーインスタンス (この名前がクライアントに表示される)
mcp = FastMCP("weather")

# ここに後で tool を追加する (#68)
# @mcp.tool()
# def get_weather(city: str) -> str:
#     return f"{city} の天気: 晴れ"

if __name__ == "__main__":
    # stdio で起動 (デフォルト)
    mcp.run(transport="stdio")
FastMCP: 公式SDK内の 高レベルAPI。デコレータ @mcp.tool() で関数を tool 化するだけで、type hints から JSON schema を自動生成してくれる。

⑥ ローカルで起動・動作確認

# 開発モード起動 (MCP Inspector付き・#69で詳述)
uv run mcp dev main.py
# → ブラウザに http://localhost:5173 等のURLが表示される
# → Inspector UI でtool一覧 / 実行 / response 確認

# 通常起動 (Claude Desktop等から呼ばれる用)
uv run python main.py
uv run の利点: .venv を activate しなくていい。uv run xxx で勝手に隔離環境で実行される。

⑦ Claude Desktop に登録する

// ~/Library/Application Support/Claude/claude_desktop_config.json
{
  "mcpServers": {
    "weather": {
      "command": "uv",
      "args": [
        "--directory",
        "/Users/abi/work/weather-mcp",
        "run",
        "python",
        "main.py"
      ]
    }
  }
}
絶対パス必須: Claude Desktop は CWD が違うので、--directory でプロジェクトパスを指定する。設定保存後 Claude Desktop 再起動。

⑧ pyproject.toml の見方

[project]
name = "weather-mcp"
version = "0.1.0"
requires-python = ">=3.11"
dependencies = [
    "mcp[cli]>=1.2.0",
    "httpx>=0.27.0",
]

[tool.uv]
dev-dependencies = []
dependencies: 通常依存 (本番でも必要) / dev-dependencies: 開発用 (pytest等)。
uv add pytest --dev で dev-dependencies に追加可能。

⑨ Git 管理 — 何を含める/除外する

# .gitignore に含めるもの
.venv/           # 仮想環境 (ローカル固有)
__pycache__/
*.pyc
.env             # secrets

# Git に含めるもの (重要)
pyproject.toml   # 依存定義
uv.lock          # 依存固定 (バージョン再現性)
main.py
README.md
uv.lock を含める: npm の package-lock.json 相当。必ず git に commit。チーム全員が同じバージョンを使えるようにするため。

⑩ TypeScript / Node.js での選択肢

# Node.js MCP サーバー
npm init -y
npm install @modelcontextprotocol/sdk zod

# minimal server (index.ts)
import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";

const server = new McpServer({ name: "weather", version: "0.1.0" });
const transport = new StdioServerTransport();
await server.connect(transport);
言語の選び方: AI界の標準は Python だが、Node/TypeScript のほうが既存資産と組み合わせやすい場面も多い。本章以降は Python (FastMCP) で進めるが、TypeScript でも同じコンセプト。

⑪ プロジェクト構造の推奨

⑫ 失敗パターン

1. Python バージョン違い

Python 3.10未満では mcp が動かない場合あり。uv init --python 3.11 で明示。

2. Claude Desktop で「server not connecting」

config の絶対パスが間違っているか、uv が PATH 通っていない。ターミナルで which uv で絶対パス確認 → config に絶対パスを書く。

3. 環境変数が読まれない

.env を読みたいなら python-dotenv 追加 → main.py で load_dotenv()。または Claude Desktop config の env フィールドで明示。

4. uv が遅い時

Pythonバイナリ初回取得は時間かかる (数十MB)。2回目以降は超速。キャッシュは ~/.cache/uv/。

⑮ 理解度チェック

Q1. uv を使う理由は?

① 10〜100倍速い (Rust製) ② venv 管理不要 (uv run で自動隔離) ③ Python本体も uv が取得 ④ Anthropic公式推奨。pip+venv より圧倒的にDX良い。

Q2. uv.lock は git に commit する?

Yes・必須。npm の package-lock.json と同じ役割。チーム全員が同じバージョンを再現できるようにするため。

Q3. FastMCP とは?

公式 mcp Python SDK 内の 高レベルAPI。@mcp.tool() デコレータで関数を tool 化するだけ。type hints から自動的に JSON schema 生成。

Q4. Claude Desktop に登録するとき何に気をつける?

① 絶対パス 必須 (Claude Desktopの CWD は違う) ② uv 自体も PATH or 絶対パス指定 ③ --directory でプロジェクトパス明示 ④ 保存後 Claude Desktop 再起動。
