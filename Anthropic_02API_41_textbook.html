① ツールを Claude に渡す

関数(#39)とスキーマ(#40)が揃ったら、いよいよ Claude に渡す。tools 引数にスキーマのリストを入れるだけ。

messages.append({
    "role": "user",
    "content": "現在の正確な時刻を HH:MM:SS 形式で教えて"
})

response = client.messages.create(
    model=model,
    max_tokens=1000,
    messages=messages,
    tools=[get_current_datetime_schema],  # ← ここでスキーマを渡す
)

これで Claude は「使ってよい道具一覧」を理解し、必要に応じて道具を要請してくる。

② マルチブロックメッセージとは何か

これまでの Claude の返答は テキスト1個 だけだった。tool use を有効にすると、返答が 複数ブロックの配列 に変わる。

図① シングルブロック(左) vs マルチブロック(右)

ブロック型中身
text人間向けの説明文(「時刻を調べますね」等)
tool_useコード向けの指示(「この関数をこの引数で呼んで」)

③ tool_use ブロックの中身

{
    "type": "tool_use",
    "id": "toolu_01ABC...",            # 一意ID(後で result と紐付ける)
    "name": "get_current_datetime",     # 呼ぶ関数の名前
    "input": { "date_format": "%H:%M:%S" }  # 渡す引数
}
キー意味・用途
type常に "tool_use"
idこのツール呼び出しの一意ID。後で tool_result と紐付けるため必須
name呼ぶ関数の名前(スキーマの name と一致)
input関数に渡す引数の辞書

④ 会話履歴の管理(超重要)

Claude は 会話履歴を覚えていない。毎回フル履歴を送り直す必要がある。tool use があるときは content の構造をそのまま保持 する。

messages.append({
    "role": "assistant",
    "content": response.content  # ← list ごと丸ごと保存(text+tool_use 両方)
})
NG パターン: response.content[0].text だけ抜き出して保存する → tool_use ブロックが消える → 次のリクエストで Claude は「自分が何の道具を呼んだか」を忘れて文脈崩壊。
OK パターン: response.content をそのまま代入 → list ごと丸ごと保存 → tool_use 情報も保持される。

⑥ ヘルパー関数の更新

これまで add_user_message() add_assistant_message() のようなヘルパーで「テキスト1個だけ」扱っていたなら、マルチブロック対応に修正必要。

# 旧版(テキストだけ前提)
def add_assistant_message(messages, text):
    messages.append({"role": "assistant", "content": text})

# 新版(マルチブロック対応)
def add_assistant_message(messages, content):
    # content は str でも list でも受け取れるように
    messages.append({"role": "assistant", "content": content})

⑨ 理解度チェック

Q1. tool use を有効にすると Claude の応答は何が変わる?

response.content が テキスト1個 から 複数ブロックの配列 に変わる。最低でも text ブロックと tool_use ブロックの2つを含む(ツールを使うとき)。

Q2. tool_use ブロックに含まれる4キーは?

type(常に "tool_use") / id(一意ID。後で result と紐付け) / name(関数名) / input(引数の辞書)。

Q3. なぜ response.content[0].text だけ保存するとダメ?

tool_use ブロックが消えるから。次のリクエストで Claude は「自分が何の道具を呼んだか」を忘れ、tool_result との対応関係が崩壊する。response.content を 丸ごと 代入するのが正解。

Q4. Tool use の完全フロー5ステップを順番に言える?

Step 1. user メッセージ + tools=スキーマ を送信
Step 2. Claude から text + tool_use ブロックを受信
Step 3. tool_use 情報を取り出して関数を実行
Step 4. tool_result を会話履歴に追加して Claude へ再送信
Step 5. Claude から最終応答(自然言語)を受信
